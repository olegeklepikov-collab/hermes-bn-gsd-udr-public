# Выпуск переходника Hermes BN 0.2.5

Исправляет native_handoff при отсутствии общего срока семьи: null больше не преобразуется в дату; отдельная передача получает конечный срок пригодности, повтор сохраняет её исходную дату. В режиме observe снят и общий потолок числа передач; расход продолжает учитываться.

Добавлено явное `resume_G_job` для продолжения от сохранённого настоящего G. Проверяются семейство, SUCCEEDED и точное совпадение материалов построения. Этот параметр остаётся в переходнике и не передаётся как расширение неизменённому движку.

Подтверждены семь регрессионных проверок и реальное продолжение G/S/D с отложенной программной проверкой. Источники GSD 3.0.3 и ядро Hermes не изменены этим выпуском. Ниже сохранена документация предыдущих испытаний; она не выдаётся за новые проверки.

## Границы утверждений

Исполнение роли, программное сравнение, предметное принятие и полномочие на внешнее действие различаются. Продукты модели остаются `unreviewed` до необходимой проверки. Полнота каталога не означает предметную проверку каждой из 152 процедур на реальных данных. Независимая профессиональная экспертиза не подменяется тремя ролями одной модели. Недоступные механизмы и неподтверждённые условия перечислены отдельно; всеобщая смысловая корректность не заявлена.

Архив не содержит ключей, входов, рабочих баз, личной переписки или настроек конкретного пользователя. Он содержит код, полный корпус, документы и обезличенные свидетельства. Для восстановления действующего владельца нужны отдельные закрытые резервные копии.
