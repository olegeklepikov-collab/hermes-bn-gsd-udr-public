# Начните с этого файла

Здесь собраны инструкции, по которым другой ИИ-агент установит и настроит для вас Hermes BN. После настройки вы сможете поручать Hermes исследования, работу с документами и другие задачи в выбранной области.

**Вы задаёте цель и входите в свои аккаунты. Агент-настройщик выполняет техническую работу.** Знать устройство компьютера, выбирать папки и запускать команды заранее не требуется.

## Три действия для начала

1. Откройте агента-настройщика, которому доступен компьютер для установки.
2. Передайте ему **всю эту папку** или ZIP-комплект. Внутри уже есть задания и технические руководства.
3. Скопируйте задание ниже. Если есть важное ограничение, добавьте его одной строкой: например, «Не изменять существующий Zotero».

> Установите и настройте новый Hermes BN по этому комплекту. Начните с «Настройщику/00 — Порядок работы.md». Самостоятельно определите устройство компьютера, совместимость и безопасную конфигурацию, сохраните другие установки. Основная модель — Sol 6.1 (`gpt-6.1-sol`), режим `high`, вход через OpenAI Codex по OAuth моего аккаунта ChatGPT. Ведите работу по всем 11 стадиям, выполняя технические действия и проверки самостоятельно. Давайте мне точные инструкции только для необходимых входов, защищённого ввода ключей и существенных решений о данных, расходах и правах. Используйте мои документы; не просите повторять уже известное. Не выдумывайте личностные нормы и предметную область. Сообщайте кратко: что готово, что делаете и что дальше. Доведите доступные работы до проверки, передачи результатов и пробного восстановления. Неподтверждённые функции не называйте готовыми.

## Что понадобится от вас

- Войти в свой аккаунт ChatGPT по новой ссылке, которую даст настройщик.
- По мере необходимости войти в Zotero, OpenRouter и выбранные сервисы. Создать свои ключи и вставить их в защищённые поля.
- Рассказать, для каких задач нужен агент, и передать имеющиеся документы о желаемом поведении и профессиональной работе.
- В конце открыть полученный отчёт и проверить, что результат отвечает вашей задаче.

**OAuth** — вход через страницу поставщика: вы входите в свой аккаунт и разрешаете подключение, не сообщая пароль настройщику. **Ключ доступа** — отдельная секретная строка для программы. Ключи, пароли и коды из писем не отправляйте в переписку.

## Совместимость и границы комплекта

Готовая сборка r8 рассчитана на **macOS с процессором Apple Silicon**. Для Windows и Unix/Linux есть инструкции по нативной установке компонентов, но полный перенос этой сборки на них ещё требует доработки и испытаний. Настройщик проверяет это в начале и прямо сообщает, какие части доступны. Установка без Docker и WSL означает работу программ непосредственно в выбранной ОС, без этих дополнительных сред.

Этот комплект содержит документы и начальные средства загрузки. Сама программная поставка скачивается из указанного выпуска. Ваш доступ к моделям, платным сервисам и понимание инструкции реальным пользователем редакторской проверкой не подтверждаются.
