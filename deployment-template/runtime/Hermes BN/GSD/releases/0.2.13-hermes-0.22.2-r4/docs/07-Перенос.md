# Перенос и состав пакета

## Общий архив

Содержит собственный код, исходную каноническую поставку 1.1.0 с Engine 3.0.3, базовый официальный исходник Hermes, универсальные изменения, отдельно прежнее исправление поиска, полный каталог навыков, документы и обезличенные воспроизводимые результаты. Контрольные суммы всех файлов — `delivery-manifest.json` и `SHA256SUMS`; ZIP проверен на CRC.

Исключены ключи, `.env`, входы ChatGPT/MCP, базы пользователя, частная переписка, журналы скрытых рассуждений, разрешения и закрытые управляющие возможности дочерних агентов. Чужие почта, Telegram ID и привязка аккаунта не являются настройками другого пользователя.

Для другого пользователя создайте отдельный профиль, новые ключи состояния и собственные входы сервисов. Не копируйте подписанные случаи, происхождение свидетельств или полномочия прежнего владельца. Ранее предъявленные подписи не становятся доказательствами нового исследования. При необходимости библиотеки и данные переносите отдельно с определённым владельцем, происхождением и допустимым доступом.

## Закрытые копии действующего владельца

Полная прежняя резервная копия окружения сохраняет основу отката. Перед GSD дополнительно создан точный зашифрованный снимок затрагиваемых файлов кода, конфигурации и окружения. Сам закрытый снимок и его ключ не входят в общий архив. Ключ хранится отдельно; резервный файл без доступного ключа не является проверенным восстановлением.

Согласованная копия GSD-состояния включает `state/`, `operator/` с ключами и независимой опорной записью, рабочую версию адаптера/корпуса и конфигурацию их привязки. Копирование базы в произвольный момент без блокировки писателей или копирование одной базы без соответствующей опорной записи неприемлемо. Перенос на другой путь требует явно проверенной перепривязки путей; состояние и расход не создаются заново.

Входы могут истечь или быть отозваны после резервирования. При восстановлении их повторная авторизация выполняется штатно; наличие старого токена в архиве не доказывает его текущую работоспособность.

## Повторение проверок

После установки собственной копии:

```bash
cd "$CORE"
scripts/run_tests.sh \
  tests/agent/test_auxiliary_required_terminal.py \
  tests/agent/test_subagent_plugin_toolsets.py \
  tests/hermes_cli/test_external_runtime_management.py \
  tests/plugins/test_required_execution_control.py \
  tests/agent/test_subagent_lifecycle.py \
  tests/agent/test_auxiliary_hooks.py \
  tests/tools/test_connector_dispatch_policy.py \
  tests/hermes_cli/test_update_contract.py \
  tests/gateway/test_multiplex_transport_matrix.py

scripts/run_tests.sh "$PKG/tests" -- \
  --gsd-settings "$BN_ROOT/GSD/operator/settings.json"
```

Испытания адаптера создают временное состояние и собственные временные ключи; рабочая база не заменяется. Для реального исполнения роли нужны действующий поставщик модели и настоящий родительский сеанс Hermes. Отдельный программный тест без такого исполнителя не считается успешным испытанием модели.

Исходные инструкции и официальная документация:

- [Плагины Hermes](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins/).
- [Официальный исходник Hermes](https://github.com/NousResearch/hermes-agent).
- Канонические документы GSD внутри `source/GSD_Integration`; действующие инструкции берутся исходным сборщиком, история не подключается.
