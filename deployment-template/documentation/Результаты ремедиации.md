# Результаты ремедиации Hermes BN

Установлены общая память 1.2.0, переходник GSD 0.2.12, переходник UDR 0.2.3. Исходная поставка GSD 3.0.3 и подписанные Research/Foundation не заменялись. Нативный Hermes — 0.21.5, commit f97608f178d1ffeca59860195ab7da295f7c8e5f с проверенным локальным дополнением. Основная модель — GPT 6.1 Sol xhigh через OAuth. Секреты не заменялись.

Исправления, выявленные реальными испытаниями, сохранены вместе с исходными отказами: устаревшая копия схемы GSD; проверка инструмента ошибочно помещена в контроллер модели; corpus_id передавался каноническому движку; отдельный процесс UDR не видел пакет памяти; task- ошибочно распознавался как ключ sk-; последовательное сохранение UDR не обновляло собственную ревизию; независимый профиль получил чужую контрольную сумму политики. Отказы не переименованы в успешные результаты.

Число проверок: core — 21; основной GSD — 53; основной Memory — 36; дополнительные границы — 16; документарный набор — 13. Контролируемые модельные ответы в локальных проверках обозначены simulated. Настоящие исполнения имеют отдельные квитанции. Не выполнялся бесконечный общий повтор: после новых ошибок повторялся изменённый путь.
