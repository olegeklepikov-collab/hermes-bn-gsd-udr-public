# Справка Zotero: profile-directory

Сохранённая внешняя документация. Копия адаптирована для переносимости: локальные пути и демонстрационные реквизиты/объекты заменены параметрами; содержимое не является конфигурацией готового аккаунта. Она описывает продукты, версии и варианты доступа, а не состояние какого-либо аккаунта. Примеры ОС, тарифов, путей и лимитов выбираются по целевой установке; числовые условия проверяются у поставщика перед использованием. Даты и исходная терминология могут относиться к версии справки.

Zotero’s profile system is based on the
Firefox profile system
.
You can find your Zotero profile directory in the following location:
Mac
${USER_HOME}/Library/Application Support/Zotero/Profiles/<randomstring>
Note: The ${USER_HOME}/Library folder is hidden by default. To access it, click on your desktop, hold down the Option key, and click the Finder’s Go menu, and then select Library from the menu.
Windows 11/10/8/7/Vista
${USER_HOME}\AppData\Roaming\Zotero\Zotero\Profiles\<randomstring>
Note: If AppData is hidden on your system, click the search bar (or Start before Windows 10), type
%appdata%
, and press Enter, which should take you to the AppData\Roaming directory. You can then open the rest of the path.
Windows XP/2000
${USER_HOME}\Application Data\Zotero\Zotero\Profiles\<randomstring>
Linux
~/.zotero/zotero/<randomstring>
