# Справка Zotero: csl

Сохранённая внешняя документация. Копия адаптирована для переносимости: локальные пути и демонстрационные реквизиты/объекты заменены параметрами; содержимое не является конфигурацией готового аккаунта. Она описывает продукты, версии и варианты доступа, а не состояние какого-либо аккаунта. Примеры ОС, тарифов, путей и лимитов выбираются по целевой установке; числовые условия проверяются у поставщика перед использованием. Даты и исходная терминология могут относиться к версии справки.

# Citation Styles<a href="#citation_styles" class="headerlink" title="Permanent link">#</a>

Zotero ships with several popular citation styles for [creating citations and bibliographies](https://www.zotero.org/support/creating_bibliographies), and over 10,000 additional styles can be found in the [Zotero Style Repository](https://www.zotero.org/styles). All these styles are written in the [Citation Style Language](https://citationstyles.org/) (CSL), a format also supported by many other programs.

## Installing Additional Styles<a href="#installing_additional_styles" class="headerlink" title="Permanent link">#</a>

### Zotero Style Repository<a href="#zotero_style_repository" class="headerlink" title="Permanent link">#</a>

You can install styles from the Zotero Style Repository by going to the Cite pane of the Zotero settings and clicking on the “Get additional styles…” option in the [Zotero Style Manager](https://www.zotero.org/support/preferences/cite). Search for the style you want and click the style title to install it into Zotero. You can also visit the [Zotero Style Repository](https://www.zotero.org/styles) webpage in your browser with the Zotero Connector installed to install styles directly into Zotero.

The repository allows you to search by style name and filter by style type and academic field of study. By checking the box “Show only unique styles”, duplicate styles that share the exact same format are hidden (e.g., for the journal-specific styles “Nature”, “Nature Biotechnology”, “Nature Chemistry”, etc., only the *independent* “Nature” style is shown).

### Alternative Installation Methods<a href="#alternative_installation_methods" class="headerlink" title="Permanent link">#</a>

You can also install CSL styles (with a “.csl” extension) from local files on your computer (e.g., styles that you edit yourself or that you download from another website). In the [Zotero Style Manager](https://www.zotero.org/support/preferences/cite), click the ‘+’ button, then find the style file on your computer.

## Managing and Editing Styles<a href="#managing_and_editing_styles" class="headerlink" title="Permanent link">#</a>

You can remove installed styles by clicking the ‘-’ button in the [Zotero Style Manager](https://www.zotero.org/support/preferences/cite). From this tab, you can also preview style output for the selected items in Zotero and [edit installed styles](https://www.zotero.org/support/dev/citation_styles).

## Reporting Style Errors<a href="#reporting_style_errors" class="headerlink" title="Permanent link">#</a>

If a CSL style doesn’t give the expected output, first make sure that you are running the latest version of Zotero and have the most recent version of the style installed from the [Zotero Style Repository](https://www.zotero.org/styles). Once you have made sure that the style deviates from the style guide, instructions for authors, or published examples, report the error in the [Zotero Forums](https://www.zotero.org/forum). For your post, use the title “Style Error: \[Name of style\]”, and give a link to, or excerpt from, the style guide that shows that the CSL style is wrong. You can also try to [edit the style](https://www.zotero.org/support/dev/citation_styles/style_editing_step-by-step) yourself.

## Requesting New Styles<a href="#requesting_new_styles" class="headerlink" title="Permanent link">#</a>

If you can’t find the style you’re looking for in the [Zotero Style Repository](https://www.zotero.org/styles), feel free to [request a style](https://github.com/citation-style-language/styles/wiki/Requesting-Styles). When requesting styles, please provide formatted references for the Campbell/Pedersen article and the Mares chapter listed on the linked page. Please also provide a link to a free-to-access article using the style (if available). You can also try to [create the style](https://www.zotero.org/support/dev/citation_styles) yourself.
