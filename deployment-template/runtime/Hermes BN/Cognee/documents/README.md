# Cognee в Hermes BN

Нативно установлен Cognee **1.6.3**. Подключён отдельный выпуск общей памяти **1.1.8**. Интеграция обслуживает весь Hermes BN: обычную работу, GSD, UDR и чтение дочерних ролей.

| Уровень | Результат |
|---|---|
| Спроектировано | Общий первичный журнал; необязательный предметный граф; адресный контекст; области, происхождение, общий ресурс, отзыв и восстановление |
| Реализовано | Настоящий SDK Cognee, нативный модельный переходник Hermes, Voyage, типизированная обработка, собственные встроенные базы, три новых инструмента существующего сервера context |
| Подключено | Три профиля BN, прежние обязательные контроллеры, списки шести каналов, навык и рабочий Telegram-шлюз |
| Проверено | Обработка делового/академического фрагмента и кода; пять режимов поиска; точные цитаты; CLI/Telegram; реальные G/S/D и UDR; самостоятельные профили; отзыв; отказ Cognee; восстановление копии; 23 проверки модуля и 14 проверок ядра |
| Системная приёмка | Обязательные пункты C01–C10 закрыты выпуском 1.1.8: урок создан, сохранён и повторно прочитан; проверены активные CLI, приложение, TUI, фоновое исполнение и Telegram. Пределы заключения раскрыты в 07-системная-приёмка.md |

Модельные шаги выполняет действующий `gpt-6.1-sol` с высоким уровнем через OAuth, векторы — действующий Voyage `voyage-4-large`. Cognee не получает отдельный облачный аккаунт или ключ модели. Исходники ядра Hermes и движков GSD/UDR сохранены; совместимость обновления проверяется до переключения.

## Документы

1. `01-схема-и-критерии.md` — схема и критерии, заданные до испытаний.
2. `02-матрица.md` — требование/источник → механизм → проверка → фактический результат.
3. `03-эксплуатация.md` — работа агента, команды инструментов, ресурс и ограничения.
4. `04-подключение-обновление-откат.md` — программная среда, подключение, обновление и восстановление.
5. `05-испытания-и-ограничения.md` — выполненные проверки и пределы подтверждения.
6. `06-источники.md` — официальные источники, версии и целостность.

Подробные результаты текущего владельца находятся рядом в `checks` и `operator/receipts`. Обезличенный переносный пакет содержит код, закреплённые зависимости, документы и сводное покрытие; это пакет интеграции, а не полная резервная копия инстанса.

7. `07-системная-приёмка.md` — итоговая системная приёмка и её пределы.
