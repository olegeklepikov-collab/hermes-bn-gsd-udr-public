# Процедуры

| Задача | Порядок | Проверка |
|---|---|---|
| Бизнес, рынок, конкуренты | Разные направления поиска pro → официальные страницы и независимые источники → SELECT по выбранным URL → таблица и синтез | Дата, рынок, единицы цены, план/факт, дубликаты компаний |
| Финансовые и нормативные сведения | Отдельный site-поиск регулятора/компании → полный первичный документ → целевое извлечение → сверка строк | Период, валюта, редакция, вступление в силу; не делать совет из одного документа |
| Академическая литература | Несколько терминологических направлений → издатель, репозиторий, DOI → чтение выбранного полного текста → доказательства в таблице | Авторы, год, тип публикации, методы, выборка, ограничения, поправки/отзывы |
| Общие исследования | Вопрос и альтернативные объяснения → поиск первичных оснований и опровержений → чтение → сопоставление | Различать факт, заявление автора и собственный вывод |
| Текущие новости | published_after/before с явной датой → чтение первичной публикации/live при необходимости | Дата события отличается от даты статьи; acquired_at не заменяет published_at |
| Исследование на прошлый момент | query_time UTC + периоды → сохранённая историческая выдача → отдельная проверка доступной версии | Неполнота индекса; сегодняшний Fetch не доказывает текст на прошлую дату |
| Корпус источников | Поиск с критериями → дедупликация URL → пакет выбранных Fetch → местный архив | Это выбранная выборка, не обход всего сайта; за обходом обращаться к Firecrawl/Tavily |
| Доказательная таблица | WEB_FETCH известных URL → SEM_EXTRACT_ALL с per_field → TRY_CAST → URL и цитаты | Извлечение всех сущностей отличается от одного значения; пропуски NULL |
| Смысловое сравнение | SEM_MATCH для включения → SEM_SCORE по узкому критерию → SEM_NORM по правилам объединения | Смысловой балл не вероятность истины; не объединять разные юридические лица без задачи |
| Повторное уточнение | FROM собственный result_set_id → WHERE/JOIN/GROUP BY → отдельный набор агрегатов | Повторно не искать прежние данные; сохранить важные результаты до истечения 30 дней |
| Отчёт по ссылке | Проверенные строки + отдельные агрегаты → brief с вопросом, единицами, охватом и ограничениями → generate_html_report | По просьбе пользователя; любой обладатель ссылки видит содержание; drawing ещё не готовность |

Глубокое исследование — процесс Hermes с поиском, чтением, проверкой и синтезом. У Search/Fetch нет отдельного асинхронного Deep Research задания. SELECT автоматизирует обработку страниц и таблиц; он не заменяет оценку качества научной работы или полноты доказательств.
