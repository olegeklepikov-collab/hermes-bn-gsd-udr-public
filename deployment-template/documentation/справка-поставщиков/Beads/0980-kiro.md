# Kiro CLI Integration

Use Beads with Kiro CLI through workspace steering guidance.

```bash
bd setup kiro
bd setup kiro --check
```

The setup command writes Beads workflow guidance to `.kiro/steering/beads.md`.
Kiro reads workspace steering files when it starts a session.

## Remove

```bash
bd setup kiro --remove
```
