# GSD 3.0.3 для Hermes BN — пакет подключения 0.1.0

Рабочая интеграция создана и испытана в отдельной копии Hermes BN. Исходники, настройки и службы основного экземпляра не менялись. Полный ввод в эксплуатацию не объявлен: требуется определить допустимые ограничения существующих инструментов, затем проверить выбранную рабочую конфигурацию.

| Часть | Спроектировано | Реализовано | Подключено | Проверено |
|---|---|---|---|---|
| Исходный Engine 3.0.3 и интеграционный слой 1.1.0 | Да | Сохранены без изменения | Отдельный процесс | Манифесты, контрольные суммы, исходные испытания |
| Жизненный цикл и обязательный контроль | Да | Расширение интерфейса Hermes, отдельный модуль | CLI, локальный шлюз, вспомогательные вызовы | Разрешённые вызовы, отсутствие обработчика, исключения, зависание, отмена |
| Дочерние роли G/S/D | Да | Штатный SubagentLifecycleService | Настоящие дочерние сеансы | Три независимых общих прогона; отдельные операции и процедуры |
| Контекст | Да | Исходное ядро, замыкание инструкций и данных, контроль окончательного запроса | В запросе каждой роли | Полный стандартный и инженерный контекст; раздельные записи без усечения |

Интеграция использует реальные инструменты, дочерние сеансы и точки допуска. Небольшое сообщение жизненного цикла маршрутизирует работу; обязательный контекст доставляется отдельно. Само наличие навыка, корректная структура ответа и завершение вызова не считаются смысловой приёмкой.

Код хоста расположен в `bn_gsd/`, `plugin/`, `worker.py`; изменения Hermes — в `release/hermes-native-controls.patch`. Исправленная поставка GSD подключается через `gsd_bridge`, не через обходной запуск внутренних средств движка.

Официальные интерфейсы сверялись с установленными исходниками Hermes и [руководством модулей Hermes](https://hermes-agent.nousresearch.com/docs/developer-guide/plugins/). Обязательная точка допуска — добавленное здесь расширение установленного Hermes, а не заявленный штатный интерфейс исходной версии.
