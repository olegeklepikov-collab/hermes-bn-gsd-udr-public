# Чистая установка: macOS Apple Silicon

1. Проверьте SHA256SUMS, распакуйте new-user в новый каталог на файловой системе с поддержкой прав и ссылок; выполните verify.py. Не используйте данные полного архива прежнего владельца.
2. Включённый нативный R 4.6.1 можно установить пакетом system-software/R-4.6.1-arm64.pkg. Подпись: `pkgutil --check-signature ПАКЕТ`. Принятие лицензии и пароль администратора выполняет владелец в системном окне. R.app располагается в /Applications/R.app, framework — в /Library/Frameworks/R.framework.
3. Прочитайте INSTALL.md. Выберите новые короткие каталоги R BN/UDR. deployment/prepare.py требует путь R, заканчивающийся /env, не длиннее 49 UTF-8 байтов; это ограничение размещения сохранённой двоичной среды, не размера данных.

```bash
python3 deployment/prepare.py --r-runtime '/КОРОТКИЙ/BN_R' --init-local-databases
python3 deployment/prepare-udr.py --r-runtime '/КОРОТКИЙ/UDR_R' --timezone 'ВАША_ЗОНА' --host-bootstrap '/НОВЫЙ/UDR-bootstrap'
python3 deployment/prepare-memory.py
```

Если нужна почта для Crossref/NCBI, передайте собственный --contact-email только после решения передавать её этим службам. Ни одну переменную HOME не переназначайте. Средства подготовки не запускают ботов и не входят в аккаунты. Они создают новые ключи и пустые состояния.
4. Включённые Homebrew Cellar и ссылки предназначены для /opt/homebrew. Сначала сравните версии и уже установленные пакеты; копируйте только отсутствующие нужные версии. Не заменяйте /opt/homebrew целиком. Точные рецепты/источники также включены. Homebrew: https://brew.sh/.
5. Проверьте CLI BN/UDR, R, локальные пустые базы и ключи. Подготовленная новая установка ещё не подтверждает модель, память через службы или производственную интеграцию.
6. Выполните руководства 06–09 этого набора и официальные UDR docs/setup. Сначала собственные пароли/службы, затем общая память и GSD/UDR. Обязательный контроль подключается совместно с готовой конфигурацией; отказ контроля закрывает зависимый путь.
7. Настройте собственную модель и входы, ботов/доступ владельца, исследовательские службы и Zotero. Проведите собственную сквозную приёмку и создайте новую точку восстановления.

Адаптер GSD 0.2.13 создаётся из текущего исходника. Политика больших задач использует observe без прежних финансовых/количественных балансов. Предельный размер одного запроса/ответа и защиты отдельного процесса сохраняются; обязательный контекст делится на адресные пакеты, а не отсекается.
