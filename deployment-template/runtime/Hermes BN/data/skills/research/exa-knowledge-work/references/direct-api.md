# Программные операции

Команда собственного профиля: `__HERMES_BN_ROOT__/bin/exa-bn`.

Сохрани тело запроса в JSON-файл задачи. Передай операцию, `--input` и `--output`:

```bash
'__HERMES_BN_ROOT__/bin/exa-bn' search --input '/путь/запрос.json' --output '/путь/результат.json'
```

Команда проверяет запрос по полученной официальной OpenAPI-схеме и использует ключ текущего профиля. Сохранённые ответы имеют права 600. Ошибки возвращают ненулевой код; не повторяй создание заданий после неопределённого исхода.

Основные операции: `search`, `contents`, `answer`, `agent-create`, `agent-get`, `agent-list`, `agent-events`, `batch-create`, `batch-get`, `batch-list`. Операции с заданием требуют `--id`. Batches принимает только POST Search и Agent в текущей схеме; каждому заданию нужен уникальный `customId`. Сохраняй ID, проверяй результат каждого элемента и конечное состояние всего пакета.

Серверный Batches требует Enterprise и отдельного включения; текущая команда ответила 403. Для обычной команды используй `batch-local` с тем же телом: два одновременных независимых вызова, результат привязан к `customId`. Если элемент Agent ещё `running`, сохрани ID и забери его через `agent-get`; не считай пакет завершённым по факту отправки запросов.

В Search содержание помещается внутрь `contents`; в Contents — на верхнем уровне рядом с `ids` или `urls`. Для большинства поисков достаточно `contents.highlights:true`; текст и краткое изложение выбираются только при необходимости. Каждый вид содержания тарифицируется отдельно. Свежесть устанавливается через `maxAgeHours`, дата публикации — отдельными фильтрами.

Search: `output.content` содержит синтез, `output.grounding` — основания для отдельных полей. Agent: `output.text` либо `output.structured`, основания в `output.grounding`. В Answer проверь фактически возвращённые `citations` и ответ. Схема и наличие ссылок не гарантируют правильность содержания.

Поддержка Monitors подготовлена: `monitor-list`, `monitor-create`, `monitor-get`, `monitor-update`, `monitor-trigger`, `monitor-runs`, `monitor-run-get`; последний требует ещё `--run-id`. Для создания нужен согласованный HTTPS-получатель. Без него не подставляй чужой адрес и не публикуй локальную службу. Если расписание ещё не нужно, пропусти `trigger`: получится ручное наблюдение. Минимальный период — один час, запуск может отклоняться от расписания до 30 минут. Сначала проверь подпись уведомления и конечный результат; рабочий приёмник настраивается по отдельной задаче.

Websets: предусмотрены безопасные чтения `websets-team`, `websets-list`, `websets-get`, `websets-items` и `websets-preview`. Websets имеет собственный доступ и баланс, отдельно от Search; для новых списков официальный поставщик рекомендует Agent. Не оформляй новый тариф автоматически. Предварительный просмотр тоже расходует Websets credits, поэтому сначала проверь доступ.

Событийные потоки и OpenAI-совместимые `/responses` и `/chat/completions` остаются альтернативным интерфейсом Exa. Основная команда забирает конечный JSON; для потока используй официальный SDK и дождись завершающего события. Они не меняют вход Hermes в его основную модель.
