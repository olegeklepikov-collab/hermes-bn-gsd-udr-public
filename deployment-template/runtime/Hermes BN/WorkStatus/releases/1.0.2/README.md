# Статус работ Hermes BN — 1.0.2

Наблюдающий модуль штатных событий и сообщений статуса. При раннем отказе обязательного контроля установленного Hermes завершает статус как blocked и останавливает периодические сообщения. Отказ сохраняется и передаётся исходному обработчику; модель и действия повторно не вызываются. Другая сессия и прежний ход не завершаются; обычное временное исключение оставлено штатному восстановлению Hermes.

Установка при остановленных собственных службах: Python установленного Hermes → `install.py --root "ПУТЬ/Hermes BN"`. Конфигурация и закреплённые суммы обновляются во всех трёх профилях; прежняя конфигурация сохраняется в WorkStatus/operator/checkpoint-*. Сам модуль не даёт полномочий, не создаёт задач или исполнителей. После установки запустите собственные службы и проверьте реальный ответ.

Шесть условий прошли: последовательные шаги/ошибки; устаревшие и дочерние события; сохранение и периодические сообщения; параллельные шаги; настоящий механизм исполнения Hermes с обёрнутым ExecutionControlDenied без вызова исполнителя и без последующих сообщений; отсутствие ложного завершения иной попытки или временного сбоя. Реальные сообщения проверяются отдельно от условных обратных вызовов.

Личные настройки, ключи, переписка и состояния не включены. Отчёт исследования также не входит в переносимый пакет.
