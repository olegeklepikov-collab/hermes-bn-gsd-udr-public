# Источники и интерфейсы

| ID | Закреплённый источник | Использованный интерфейс |
|---|---|---|
| H-PLUGIN | Hermes BN 0.21.5, commit f97608f178d1ffeca59860195ab7da295f7c8e5f; hermes_cli/plugins.py | register_hook, register_middleware, register_execution_control |
| H-CONTROL | hermes_cli/execution_control.py | обязательная проверка tool/tool_result/llm/auxiliary |
| H-SURFACE | hermes_cli/tools_config.py; gateway/run_turn.py | platform_toolsets и штатное разрешение набора инструментов |
| H-SESSION | gateway/session.py | SessionStore.reset_session, сохранение истории |

| SR-MCP | Serena tools/symbol_tools.py | get_symbols_overview, find_symbol, find_referencing_symbols |

Дополнительные официальные инструкции: [Cognee MCP](https://docs.cognee.ai/cognee-mcp/mcp-overview), [Cognee recall](https://docs.cognee.ai/core-concepts/main-operations/recall), [Zvec](https://zvec.org/en/docs/), [Serena](https://oraios.github.io/serena/02-usage/030_clients.html), [AgentMemory](https://github.com/rohitg00/agentmemory).

Cognee рассмотрен как альтернативный механизм памяти и предметных схем. Для текущей задачи дополнительная установка увеличила бы число хранилищ без обязательной новой функции. Его качество на пользовательском массиве не испытывалось; превосходство над текущим поиском не заявлено.

Подписанные поставки Research/Foundation и канонические источники GSD не переписаны. Новый код находится в отдельном выпуске Memory/releases; манифест и допуск GSD привязаны к фактическим хешам. Новая версия Hermes требует проверки изменившихся интерфейсов; прежняя приёмка не переносится автоматически.
