# Фундамент идентичности Hermes BN — 0.1.0

Частное версионное хранилище текущего экземпляра. Содержание существующих трёх `SOUL.md` сохранено без изменений. Глубинные разделы зарезервированы как `null`.

Команды: `python3 identity_store.py verify`; `capture --reason 'причина наблюдения'`; `export --revision ID --profile main --output /абсолютный/новый/файл.md`. Полный путь к утилите допускается из любого рабочего каталога. `--root` передаётся до команды и предназначен для отдельно подготовленного хранилища.

`observed.json` указывает наблюдённую редакцию, а не одобрение или активацию. Рабочий Hermes продолжает читать профильный `SOUL.md`. Утилита не изменяет эти файлы; выгрузка подготавливает копию для последующего решения о восстановлении. Сохранение редакции не доказывает её одобрение владельцем.

Системные права не отделяют утилиту от других программ того же пользователя. Не публиковать частные редакции в обезличенной поставке. Новые редакции в этой версии не могут определять глубинные разделы; расширение потребует новой версии договора.

Полный договор, устройство слоёв, порядок изменений, перенос и ограничения: [GUIDE.md](GUIDE.md). Это копия одноимённого документа из пользовательской папки Hermes New Edition, включённая для автономного хранения инструкции вместе с утилитой.
