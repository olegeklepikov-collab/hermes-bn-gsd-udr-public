# Смысловые испытания 152 процедур GSD

Испытаны все **152** канонические процедуры: G — 27, S — 55, D — 70. Для каждой выполнены условия A и B на реальном материале; B — намеренно ошибочное производное предложение. Свидетельства содержат реальные квитанции дочерних агентов, входы и адресуемые выходы. GA-01…GA-12 выполнены двенадцатью отдельными вызовами.

Итог последней проверки: {'pass': 136, 'limited': 5, 'blocked_scope_success': 11}. Отрицательные условия: {'pass': 152}. Незакрытые ошибки: нет. Ограниченный результат и безопасный отказ учитываются отдельно от полного положительного результата.

## Материал и область подтверждения

1. Опубликованный издательский PDF метаанализа обратной связи, DOI 10.3389/fpsyg.2019.03087: целевое чтение страниц 1, 6, 7, 11 и визуальная сверка таблицы 3. Полное чтение всех первичных исследований не заявлено. [Издатель/DOI](https://doi.org/10.3389/fpsyg.2019.03087), [PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC6987456/).
2. Реальный набор iris установленного R: 150 строк, три группы по 50, единицы сантиметры; реальные расчёты R и Python. [Официальная документация](https://www.stat.ethz.ch/R-manual/R-devel/library/datasets/html/iris.html).
3. Реальные журналы отказа Hermes, установленный код до/после исправления, квитанции настоящих G/S/D, изоляции, переноса состояния и восстановления файлов.
4. Заранее заданное локальное действие AP2: проверенное разрешение, фактическое создание, независимое чтение и восстановление файла. Это испытание локального артефакта, а не восстановления всей службы или воздействия на людей.

## Метод

Критерии зафиксированы до испытаний. Для каждого ID сохранены точная операция, постусловие, исходные адреса и отпечатки. Обязательный канонический контекст доставлялся целиком; квитанция фиксирует проверенные фактические аргументы поставщика модели. Дочерние роли работают без инструментов и рекурсивного делегирования. Исходная процедура выполнялась как отдельная смысловая операция; это не заявление о 152 успешных фиксациях одного случая в ProcedureEngine.

Отдельный новый контекст S сопоставлял реальные продукты с исходными требованиями; результат сопоставления проверен по конкретным свидетельствам и замечаниям. Та же модель в новом контексте не является независимым экспертом. SUCCEEDED, наличие JSON или номера процедуры не служили смысловым критерием.

Повторные испытания адресно устраняли отсутствующие входы, ошибки композиции исключительных причин и неверное приписывание наблюдений. Старые входы, продукты, замечания и остановки сохранены. Пустое измерение, неизвестность и отсутствие полномочия не заменялись вымышленным результатом.

## Исправления и восстановление

- Точное выполнение адресованной операции вместо навязывания полного причинного разбора подготовительной процедуре.
- Доверенная привязка результата к входу после проверки фактической доставки. Подмена роли, статуса, дополнительных полей или неподтверждённая доставка закрывают путь.
- Временной предел частного испытательного инструмента увеличен с 420 до 1800 секунд для реальных последовательных GA-вызовов; предел дочерней роли и общий срок сохранены. Неизвестный расход учтён, продолжение не пополнило бюджет.
- Повторное создание уже начатого задания отклоняется; запись CLI с кодом 0 не принята вместо результата исполнителя.
