# Установка, запуск и эксплуатация

Сначала: [официальная точка входа](https://github.com/olegeklepikov-collab/hermes-udr/blob/main/docs/setup/README.md), затем три исходных документа спецификации, дорожной карты и передачи задания; применимые руководства docs/setup/ru/01–11. Точные версии закреплены в native-tools.lock.json. Используйте архивы согласованного выпуска v0.44.0-beta.2 и Minisign; не заменяйте ключ доверия содержимым нового архива.

Установка нативная: SQLite, Beads, Dolt, AgentMemory/iii, Graphiti/Neo4j, Zvec, Serena, Mirage, R и средства наблюдения. Docker/WSL не используются. Выделенные каталоги и профили обязательны. Не копируйте чужие ключи, входы и идентификаторы владельца.

Исходники соединения: `${UDR_ROOT}/operator/bn-bridge`. Установщик install.py применяет проверенные настройки, отдельное расширение, MCP и два независимых профиля. Он отказывается перезаписывать существующее расширение/профили. До запуска нужен подтверждённый контрольный пакет отката и успешный staging-controls.json. Значения путей, владельца и каналов в установщике этого экземпляра предварительно адаптируются при переносе; это не универсальный установщик для любого пользователя.

Команды действующего экземпляра:

```bash
source "${BN_ROOT}/environment.sh"
"${BN_ROOT}/bin/hermes-bn-telegram" status
"${BN_ROOT}/bin/hermes-bn-telegram" start
"${BN_ROOT}/bin/hermes-bn" -p bn-gsd-only chat
"${BN_ROOT}/bin/hermes-bn" -p bn-udr-only chat
"${BN_ROOT}/hermes-agent/venv/bin/python" "${BN_ROOT}/bin/hermes-bn-module-mode.py" status
```

Выбор следующей задачи через основной бот:

```bash
"${BN_ROOT}/hermes-agent/venv/bin/python" "${BN_ROOT}/bin/hermes-bn-module-mode.py" gsd
# либо udr, либо combined
```

Это меняет штатное правило маршрутизации к отдельному профилю и перезапускает принадлежащий BN шлюз. Старые материалы не удаляются; перед несвязанной новой задачей используйте /new. /profile показывает текущий профиль, а не переключает его.

В совместном режиме начните с навыка bn-udr-host-work. Три MCP-интерфейса: udr_research, udr_recall, udr_status. Действия исследования: start/status/plan/source/document/note/fetch/method/compare/build_report/workspace/finish/read/stop. method_action открывает полный канонический каталог/описание/исполнение метода; workspace_action — сохранённые рабочие пакеты и ход работы. URL local.invalid обозначает местный источник, не посещённый сайт.

Search не требует пустых уровней глубокой методологии. Один успешный план достаточен до появления новых существенных оснований. Эквивалентную задачу в общей базе hbn создавать не следует: start возвращает канонический Bead KWF. Для общей задачи BN и её исследовательской части сохраняется связь между уровнями.

Статус finish: complete либо partial. Недопустимый статус не замораживает отчёт. После подготовки неизменяемого пакета исправление текста требует нового явного результата; повтор завершения должен содержать идентичный отчёт. Передача файла выполняется отдельным доверенным операторским путём после независимой проверки и точного разрешения владельца.
