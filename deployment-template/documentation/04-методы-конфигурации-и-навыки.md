# Применение методов, конфигураций и навыков

Шаблоны находятся в `шаблоны/`, общие инструкции для адаптации — в `навыки/`. Они описывают функции и параметры; фактический доступ определяется целевой установкой.

Профиль задаёт начальные параметры, которые дополняются задачей. Период, регион, язык, библиотеки, базы, рабочие пространства и бюджет задаёт пользователь. Публичный пример не является разрешением запускать его автоматически. `${...}` заменяется JSON-значением нужного типа; сохранение строки вместо числа/массива может нарушить схему.

Официальный API, удалённый MCP и местный переходник могут иметь разные возможности. Перед вызовом получить текущую схему. Поиск/описание большого набора делить по фактическому пределу клиента. В испытанной реализации требовались группы до 7 поисковых запросов и до 10 имён описаний; для другой версии проверить эти значения заново.

Ошибку параметров описания исправляют без повторной записи данных. После ошибки записи/таймаута сначала проверяют существование созданного объекта или задания. Частичные результаты не отбрасывают из-за внешнего HTTP 200 либо ошибки одного элемента. Подмену источника обозначают явно.

Расширения записи аккаунта, публичных отчётов, отправки уведомлений, удаления и платных запусков выбираются отдельно по текущему поручению. Отключённый метод не включается только потому, что его имя есть в каталоге.
