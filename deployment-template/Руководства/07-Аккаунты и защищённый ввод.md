# Собственные доступы нового владельца

Секреты вводятся в защищённой местной форме/штатном диалоге Hermes. Они не помещаются в руководства, общий YAML, командную строку или чат. Не используйте ключи полного архива другого владельца. Для OAuth авторизацию выполняйте в собственном браузере и аккаунте; разрешения и юридические условия подтверждает новый владелец.

| Подключение | Начальная официальная страница / действие |
|---|---|
| Hermes/модели | Штатные `hermes setup` / настройка model; для Codex OAuth — собственный ChatGPT-вход, код генерируется новой установкой |
| Эмбеддинги | https://dashboard.voyageai.com/ ; собственный ключ. Модель/размерность/нормализация фиксируются перед индексированием. Подписка ChatGPT не даёт ключ Voyage или иной API |
| Firecrawl | https://www.firecrawl.dev/app/api-keys |
| Exa | https://dashboard.exa.ai/api-keys |
| Tavily | https://app.tavily.com/home |
| Keenable | https://app.keenable.ai/console/api-keys |
| Nimble | https://online.nimbleway.com/settings/api-keys |
| Parallel | https://platform.parallel.ai/ ; собственный API key / MCP доступ |
| Consensus | Собственный кабинет/API-доступ на https://consensus.app/ |
| Scite | https://scite.ai/ ; собственное MCP OAuth и подтверждение условий |

| Telegram | https://t.me/BotFather ; новый бот/токен и числовой ID своего владельца; не занимайте бот действующей установки |
| Zotero | https://www.zotero.org/ ; собственный аккаунт, местная библиотека/синхронизация и свои права API |

Wolfram имеет включённый вариант без отдельной местной лицензии; местный Mathematica/Engine требует собственного права использования. ASReview, Beads, Dolt и R используют локальные состояния, не нуждаются в чужих аккаунтах. eLIBRARY/DisserCat/КиберЛенинка имеют ограничения прямого доступа: внешний поиск и локальные предоставленные файлы не называйте прочитанными оригиналами площадки.

Подключайте сервис по одному: секрет/вход → здоровье → реальный минимальный запрос → чтение источника → сохранение/чтение → запись фактического состояния. Только затем включайте его в общую работу. Перевыпуск постоянного ключа, покупка подписки, публикация и сообщение третьему лицу не выполняются установщиком автоматически.
