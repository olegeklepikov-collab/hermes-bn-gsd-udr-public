# Что рассказать о будущем агенте

Редакция 4 · 11 ноября 2026 года.

Это необязательные подсказки для пользователя и перечни полноты для настройщика. Достаточно передать цель, ограничения и имеющиеся документы. Настройщик сам извлекает известные сведения и спрашивает только существенное недостающее. Сохраняйте формулировки своих целей; технические параметры определяет настройщик. Если ответа нет, пишите «Не определено». Пароли, коды и ключи сюда не добавляйте.

Онтология — описание понятий выбранной области и правил их связи. Личностный профиль задаёт устойчивое поведение, а профессиональная роль — работу, методы и границы ответственности. Эти три слоя согласуются, но не заменяют друг друга.

## Как использовать формы

Можно ответить своими словами, приложить готовые документы или оставить часть полей пустой. Настройщик использует формы как перечень того, что нужно выяснить; повторно спрашивать сведения из ваших документов он не должен.

Для онтологии слово «объект» означает то, о чём хранятся отдельные сведения: например, документ, договор или событие. «Состояние» — положение объекта в данный момент; «переход» — изменение состояния. «Свидетельство» — материал, на который опирается утверждение. Оно оценивается применительно к конкретному вопросу, а не считается безусловным доказательством.

В показателях «знаменатель» — число в нижней части дроби: оно задаёт, среди каких случаев считается доля. «Агрегирование» — объединение отдельных значений в общий показатель. Если эти правила неизвестны, назовите пробел; формулу должен обосновать настройщик.

## А. Для начала установки

Достаточно дать настройщику доступ к машине и этот комплект. Дополните только то, что существенно и не определяется осмотром:

```text
Для каких задач нужен агент:
Мой доступ к экрану целевой машины во время настройки:
Что нельзя изменять; какие данные нельзя передавать наружу:
Имеющиеся библиотеки/документы, которые нужно использовать:
Ограничения расходов и иных действий с последствиями:
```

**Неизменный исходный выбор:** OpenAI Codex → OAuth собственного аккаунта ChatGPT → Sol 6.1 (`gpt-6.1-sol`) → `high`. Пароль, код из письма и ключ API в анкете не указываются.

**Самостоятельно определяет настройщик:** ОС, архитектуру, память, диск, права, существующие установки, зависимости, свободные порты, размещение программ/состояний/проектов, подходящее руководство, порядок запуска и автозапуск. Зафиксировать это в паспорте экземпляра — его работа. Размещение пользовательских данных уточняется только при реальной неоднозначности.

**По мере необходимости уточняет настройщик:** существующий аккаунт/библиотеку Zotero, нужную синхронизацию, аккаунт OpenRouter, имеющегося бота и доступы поисковых сервисов. Необязательно собирать всё до начала установки.

## Б. Перед подключением сервиса

Передайте настройщику сведения, кроме секретов. Техническую часть таблицы заполняет он.

| Поле | Значение |
|---|---|
| Сервис и нужные задачи | |
| Собственный аккаунт и доступный план | |
| Доступ: ключ / браузерный вход / без ключа | |
| Разрешённые операции: чтение, запись, длительные задания | |
| Ограничения данных и расходов | |
| Официальная страница входа или ключей — даёт настройщик | |
| Защищённое поле и устройство для ввода — даёт настройщик | |
| Проверенные функции и дата — фиксирует настройщик | |
| Непроверенные функции и причина | |

Для векторной модели настройщик дополнительно фиксирует точный идентификатор, размерность, язык, параметры обработки текста, использующие её компоненты и результаты смыслового поиска. Для основной модели — способ входа, точное программное имя и проверенные возможности. Сам ключ в реестр не включается.

## Д. Перед разработкой глубокой предметной онтологии

Обязательная часть определяет полноту задания, но не обязательность заполнения пользователем каждого поля. Настройщик сначала использует документы и контекст; согласует только отсутствующие решения о цели и границах. Дополнительную часть разрабатывает по материалам и исследованию.

### Д.3. Как задавать вопросы проверки

Формулируйте вопрос вместе с условиями ожидаемого ответа:

| Вопрос | Что должно быть различено | На чём проверить |
|---|---|---|
| Кто вправе изменить объект и при каких условиях? | Роль, назначение, полномочие, действие и ограничение | Два случая с разными правами |
| Как изменилось значение и сопоставимы ли периоды? | Показатель, определение, единица, период, версия расчёта | Изменённое правило подсчёта |
| Какие основания поддерживают или опровергают утверждение? | Источник, фрагмент, утверждение, контекст, статус проверки | Противоречащие источники |
| Почему ответ пока невозможен? | Неизвестное, непрочитанное, неприменимое, отсутствующее | Неполные данные |

Это образцы формы вопроса, а не обязательные сущности вашей области. Содержание и степень детализации определяются вашими решениями и материалами.
