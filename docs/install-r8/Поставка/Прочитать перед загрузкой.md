# Получение r8

Средства в этой папке относятся к публичному самостоятельному r8 от 11 ноября 2026 года. Предыдущие основы и слои не нужны.

Архив Hermes-BN-GSD-and-UDR-new-user-20261111-r8.tar.zst: 18371819515 байт; SHA-256 `96a069fe07eae1098e2f9741e4e54a191f3fdc39ba77bed9a1f0d7c77b9ec948`. Точный порядок и суммы частей задаёт recovery-set.json. restore.py скачивает части и проверяет каждую из них и собранный архив. Самих многогигабайтных частей в этом небольшом комплекте инструкций нет.

[Публичный выпуск](https://github.com/olegeklepikov-collab/hermes-bn-gsd-udr-public/releases/tag/public-2026-11-11-gsd-udr-full-r8). Личный ключ зашифрованного резерва не нужен. Для уже установленной копии предусмотрено небольшое исправление Hermes-BN-r8-repair.zip и руководство 05.
