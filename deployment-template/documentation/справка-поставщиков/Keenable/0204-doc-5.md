Title: Changelog
URL: https://docs.keenable.ai/changelog

​

**Pay per request with x402** — search and fetch can now be bought one call at a time, with no account and no API key. `/v1/x402/search` and `/v1/x402/fetch` answer `402` with an [x402](https://www.x402.org) offer; the client pays $0.01 in USDC on Base and retries, and gets the result with an on-chain receipt. Any standard x402 client works. See [Pay per request](https://docs.keenable.ai/pay-per-request).**Auto top-up** — purchased credits can now refill themselves. Set a threshold, an amount and a monthly limit under Billing in the console, and Keenable charges your saved card whenever your balance falls below the threshold. A declined card turns it off and emails you; nothing is retried. See [Auto top-up](https://docs.keenable.ai/auto-top-up).**Built into Hermes Agent.** Keenable ships in [Hermes Agent](https://docs.keenable.ai/integrations/hermes-agent) as a bundled web backend for `web_search` and `web_extract`, with no plugin and no key. `hermes config set web.backend keenable` selects it; the standalone `hermes-keenable-web` plugin is no longer needed.

​

**Keenable on Baseten** — web search and page fetch run as [server-side tools](https://docs.keenable.ai/integrations/baseten) on Baseten Model APIs. Name the two tools in a chat request and the model searches and reads pages inside Baseten’s inference loop; no MCP client and no Keenable key, because Baseten meters the calls onto your Baseten invoice.**Keenable SELECT in both directories** — the [SELECT](https://docs.keenable.ai/select) server is now a listed connector in Claude (Settings → Connectors → **Keenable SELECT**) and a published plugin in OpenAI’s Plugins Directory, shared by ChatGPT and Codex. Both sign you in with your Keenable account; nothing to paste. The custom-connector and developer-mode routes keep working for accounts the listings have not reached yet.

​

**Point-in-time search** — [`query_time`](https://docs.keenable.ai/mcp-server#point-in-time-search) is now documented on both the MCP tool and the [Search API](https://docs.keenable.ai/api-reference/search): search the index as it stood at an instant, and have relative date filters resolve against that instant rather than now.**Two more search parameters** — `max_results` caps how many results come back (1–50), and `snippet_max_length` caps the snippet per result. Both are documented on the [MCP server](https://docs.keenable.ai/mcp-server) and [Search API](https://docs.keenable.ai/api-reference/search) pages.**Integrations directory** — a [catalog](https://docs.keenable.ai/integrations) of the frameworks, agents and editors Keenable plugs into, with one-click installs where the client supports them. Added this month: Claude, Convex, OpenCode, Pipecat, the Vercel AI SDK tool package, Lightpanda, LibreChat, and a listing in the OpenAI Plugins Directory.**Keyless endpoints, written down** — `/v1/search/public` and `/v1/fetch/public` are documented in the [API reference](https://docs.keenable.ai/api-reference). They exist to evaluate the API without an account; keyed access is what production use wants.**Credits, on their own page** — the monthly credit allowance and the per-SKU pricing model moved out of Rate limits into [Credits](https://docs.keenable.ai/credits).

​

**Prompt-driven extraction** — the [Fetch endpoint](https://docs.keenable.ai/api-reference/fetch) accepts a `prompt`, and returns what an LLM read out of the page for that instruction instead of the whole page.**Usage and overrides over MCP** — every authenticated tool call now reports its cost under [`_meta["keenable/usage"]`](https://docs.keenable.ai/credits#reading-usage-per-call), and an integrator can pin the search mode with [`_meta["keenable/overrides"]`](https://docs.keenable.ai/mcp-server#operator-overrides-request-meta).**Date-only cutoffs cover the whole day** — a bare `YYYY-MM-DD` on `acquired_before` / `published_before` now resolves to `23:59:59.999` on that date, so pages from the named day are kept at either end of a window. Pass a timestamp to cut at an exact instant.

​

**Live fetching on the Fetch API** — the [Fetch endpoint](https://docs.keenable.ai/api-reference/fetch) now accepts a `live` parameter to retrieve a page in real time instead of serving the cached copy. Use it when freshness matters more than latency.**Published rate limits** — request limits are now documented: 10 requests/second per organization for authenticated API keys, and a 1,000 requests/hour quota for unauthenticated use. See [Rate limits](https://docs.keenable.ai/rate-limits).**One-click MCP install** — added one-click install buttons for Cursor and VS Code (including VS Code Insiders) so you can add Keenable to your editor without editing config by hand. See [MCP server](https://docs.keenable.ai/mcp-server).

​

**Unauthenticated access** — the [CLI](https://docs.keenable.ai/cli) and [MCP server](https://docs.keenable.ai/mcp-server) now answer requests without an API key, on a shared public tier, so you can evaluate them before creating an account. See [Authentication](https://docs.keenable.ai/authentication).**Authentication & rate-limit guides** — new [Authentication](https://docs.keenable.ai/authentication) and [Rate limits](https://docs.keenable.ai/rate-limits) pages cover the device-code login flow, API keys, and the unauthenticated vs. authenticated tiers.

​

**Keenable API launch** — the initial public release of the Keenable platform for AI agents: the [Search API](https://docs.keenable.ai/api-reference/search) (`/v1/search`), the [Fetch API](https://docs.keenable.ai/api-reference/fetch) (`/v1/fetch`), the [CLI](https://docs.keenable.ai/cli), and the [MCP server](https://docs.keenable.ai/mcp-server) — one API key across all of them.
