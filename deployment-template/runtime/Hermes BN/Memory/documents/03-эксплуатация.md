# Эксплуатация

## Подключённые механизмы

SQLite хранит полный текст записей, происхождение, версии, текущие ссылки, отзыв, очередь индексов, бюджет и журнал доставки. AgentMemory хранит производные записи изолированных областей. Graphiti/Neo4j обслуживает типизированный граф записей и предметных связей через закреплённый Neo4jDriver; автоматическое модельное извлечение новых отношений не включено. Zvec хранит отдельные коллекции областей с Voyage `voyage-4-large`, 1024 измерения. Mirage читает страницы файлов; Serena читает символы и ссылки в зарегистрированном проекте.

Перед каждым ходом доставляются общие предпочтения и адресно найденные целые записи первичного журнала. Дополнительный объединённый поиск выполняется инструментом `memory_recall(mode=hybrid)`; на каждом повторном обращении к модели индексы заново не запускаются. Дочерние роли наследуют контекст, область и только чтение. Общий слой работает независимо от запуска UDR.

Beads остаётся учётом содержательных задач, Dolt — версиями структурированных таблиц. Их задачи и состояния не дублируются в новом списке. Ссылки на задачи и версии можно указывать в source_ref записей. Штатные журналы Hermes/GSD/UDR сохраняются; SQLite дополнительно регистрирует доставку общего контекста.

## Инструменты

| Инструмент сервера context | Назначение |
|---|---|
| memory_record | Сохранить запись с source_ref, kind, request_id и областью task/project/owner |
| memory_recall | local: SQLite; hybrid: также AgentMemory, Graphiti/Neo4j, Zvec |
| memory_read | Прочитать целую запись и указанную версию, проверить хеш |
| memory_retract | Отозвать текущую версию; история остаётся, индексы получают удаление |
| memory_sync | Один ограниченный проход очереди своей области |
| memory_scope | Выбрать проект, зарегистрированный владельцем |
| memory_status | Область, версии и очередь своей области |
| memory_files | Страница файла через Mirage или список каталога |
| memory_code | Serena: overview, symbol, references |

Программные имена: `mcp__context__memory_record` и далее по таблице. Модель не передаёт свою личность или родителя: подпись добавляет расширение Hermes. `local:относительный/путь` проверяет текущий исходник и связывает запись с его хешем; kind=source требует точной цитаты. Неподтверждённая заметка остаётся unreviewed.

## Ограничения размеров и расходов

Одна запись — до 8192 байт; запрос — до 1024 знаков; страница файла — до 8192 знаков при исходнике до 65536 байт. Большой материал разбивается явно. Общий контекст ограничен 6000 байтами записей; записи не обрезаются, отложенные ID остаются доступными через memory_read. Страница поиска — до 10 записей.

Voyage используется только для явного объединённого поиска и индексации; векторы кэшируются. Общая дневная квота — 1000000 учтённых входных байт, резервируется атомарно для всех сеансов. Это предел объёма, а не обещание фиксированной денежной стоимости. Новых языковых моделей и второго управляющего цикла нет.

## Местные команды владельца

Из каталога Hermes BN:

```sh
source environment.sh
hermes-agent/venv/bin/python Memory/memoryctl.py status
hermes-agent/venv/bin/python Memory/memoryctl.py sync
hermes-agent/venv/bin/python Memory/memoryctl.py register-project project-name /absolute/project/path --languages python
```

После регистрации проекта перезапустите только шлюз BN. Serena использует защищённую конфигурацию в Memory/state; настройка запуска из `.serena/project.yml` рабочего каталога не исполняется. Проверен Python; другие языковые серверы выбираются владельцем и проверяются отдельно. Набор инструментов context добавлен во все существующие списки каналов: cli, gui, api_server, telegram, tui, cron.

## Новое подключение

Требуются уже установленные BN/GSD и UDR с действующей парой Research/Foundation и их нативными зависимостями. Собственные доступы пользователя вводятся штатными защищёнными способами; ключи предыдущего владельца не переносятся. Скопируйте код Memory без state/checkpoint/checks/settings.json. Остановите шлюз BN. Выполните:

```sh
hermes-agent/venv/bin/python Memory/bootstrap.py --bn-root /absolute/Hermes-BN --udr-root /absolute/Hermes-UDR
hermes-agent/venv/bin/python Memory/activate.py
```

bootstrap откажется перезаписывать существующие конфигурацию и ключ. activate сохраняет точку отката и откажется повторно использовать прежнюю точку. Для этого экземпляра установка уже выполнена — эти две команды повторять не требуется. Запустите штатный шлюз и проверьте запись, поиск, чтение и контекст со своими доступами.
