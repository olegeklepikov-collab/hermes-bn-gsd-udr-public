# Общая память и Cognee для нового владельца

Включены актуальная общая память 1.2.4, Cognee 1.6.4, весь установленный программный состав и исходный пакет. Старые оригиналы, графы, записи памяти, уроки, сеансы, бюджеты и ключи отсутствуют. Для этого экземпляра успешная работа внешних служб ещё не подтверждена.

После подготовки BN и UDR выполните deployment/prepare-memory.py. Он создаёт собственный ключ, UUID и пустую SQLite без вызовов модели. Подготовьте собственные доступы Neo4j, AgentMemory и эмбеддингов. Проверьте свободные порты в Memory/settings.json. Затем при остановленном шлюзе вызовите Cognee/operator/connect.py для версии 1.2.4 после подготовки обязательных контроллеров; исторический Memory/activate.py относится к 1.0.3 и для новой установки не применяется. Включайте обязательные средства контроля совместно, сохраняя возможность независимой работы GSD и UDR.

Cognee хранит графы, векторы и уроки отдельно по областям доступа. Первичные документы и их происхождение сохраняются в общей памяти; модельные уроки остаются кандидатами, а не разрешением на действия. Перед использованием выполните собственные проверки записи, поиска, чтения оригинала, изоляции, восстановления и отказов. Не используйте прошлую приёмку как основание допуска нового владельца.
