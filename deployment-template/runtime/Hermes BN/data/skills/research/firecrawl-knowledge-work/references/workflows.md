# Условные последовательности

## Деловое исследование

Определи рынок, регион, период и единицу анализа. Начни с официальных сайтов компаний, отчётности, ведомств и первичных статистических таблиц; затем добавь независимые источники. Для сравнения компаний собирай одинаковые поля, даты и валюты. Заявление компании обозначай как её заявление. Оценку рынка показывай с формулой и допущениями, а не как готовый факт.

Alexandria: найди поставщика, прочитай контракт выбранной возможности с `capabilities` и `providers`, проверь обязательные поля, `requiresOneOf`, цену, версию, ключ ответа и пагинацию. Адреса возможностей и параметры бери из ответа, не угадывай. Сохраняй `requestId` для одной неизменной операции. Общий `success:true` не исключает ошибки внутри `data.alexandria`. Платные вызовы неизвестного объёма предварительно оцени; условия передай администратору.

## Научное исследование

1. Сформулируй вопрос, понятия, варианты терминов, период и критерии включения из задачи.
2. Выполни `firecrawl_research_search_papers`; `from`/`to` относятся к дате создания или обновления индексной записи, не всегда к дате публикации.
3. Используй возвращённый `paperId` в `inspect_paper`; сохрани название, авторов, DOI/идентификаторы, год, ссылки и статус доступа.
4. Вызови `read_paper` с конкретным вопросом. Сохрани возвращённые разделы, отрывки и ссылки. Если текст недоступен, ищи легальную опубликованную версию через Scrape; обозначь предел вывода.
5. Расширь подборку через `related_papers` в режимах `references`, `citers`, `similar`. Это кандидаты, а не подтверждение качества.
6. Сопоставь дизайн, выборку, измерения, эффект, неопределённость и ограничения. Разделяй предварительную и рецензированную публикации. При систематическом обзоре сохраняй поисковые выражения, даты, отбор и исключения; индекс Firecrawl сам по себе не даёт исчерпывающего поиска.

## Документы и динамические страницы

Публичный PDF: Scrape с `pdfOptions.maxPages`. Локальный согласованный файл: первый Parse возвращает краткоживущие инструкции загрузки и `uploadRef`; проверь адрес назначения и передай только выбранный файл, затем повтори Parse. Не сохраняй подписанный адрес в открытом отчёте. Учитывай `numPages`/`totalPages`, страницы и блоки. Различай физический номер PDF и печатный номер. Для DOCX/XLSX/HTML отсутствие PDF-страниц не является ошибкой.

Interact: выполняй чтение, навигацию и раскрытие публичных сведений. Сохрани `scrapeId`, закрой его через `interact_stop` в блоке завершения. Учётные записи, cookies, отправка форм и изменения требуют отдельной авторизации пользователя. Самостоятельная среда Browser доступна через SDK/REST, когда нужен длительный программный сеанс; для обычных исследований достаточно Interact.

## Наблюдение

Начни с однократного сравнения `changeTracking`. Для повторений установи цель, список URL или запросов, интервал, часовой пояс, ограничение результатов, срок хранения и получателей. API создания не принимает `status`: для предварительного примера сразу после создания с отложенным расписанием выполни Update с `status:paused` и проверь Get. Пример не содержит email/webhook. После явного запроса создай рабочую конфигурацию по действующей схеме Monitor. Проверь собственно конечный check и страницы, а не только факт постановки в очередь. При выключении поставь на паузу; постоянное удаление требует намерения пользователя удалить.
