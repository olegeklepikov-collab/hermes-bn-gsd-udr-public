# Отбор и подтверждение источников

## Деловые задачи

Определи рынок, период, регион и сопоставимые поля. Компании ищи через `company`, отчётность — через `financial report`, профессиональные связи — через `people`, если это часть запроса. Страница компании подтверждает её собственное заявление; независимый факт требует соответствующего первичного свидетельства. Для чисел сохраняй валюту, единицу, период и определение показателя.

Для макроданных предусмотрен Connect `macrobond`; для отчётности и рыночных наборов — `financial_datasets`; для публичных подкастов — `particle`. Включай лишь подходящий поставщик и формулируй, какие поля должны получаться из него. У Macrobond и Polymarket нет отдельной цены партнёра, но Agent тарифицируется. Другие партнёры добавляют цену; точные ставки находятся в документации и `connect-profiles.json`.

Изученные доступные поставщики: fiber, similarweb, baselayer, polymarket, macrobond, affiliate, particle, financial_datasets, jinko. Они применяются по запросу, а не все вместе. Обогащение частными контактами, KYB-проверки и операции с личными данными не включаются в обычный исследовательский поиск.

## Академические задачи

Начни с критериев включения и нескольких разных формулировок вопроса. Используй `publication`, официальный текст статьи, DOI и профильные репозитории. Явные доменные фильтры нужны только при заданном ограничении источников. Для широкого междисциплинарного поиска не замыкай подборку на arXiv или PubMed.

Сохраняй автора, название, год, версию, источник, DOI/идентификатор, статус рецензирования, доступность полного текста и ограничение прочтения. Отрывок, аннотация и полный текст различаются. Проверяй отзыв публикации и существенные сведения по первичному источнику. Для сравнений выделяй дизайн, выборку, измерения, эффекты, неопределённость и ограничения.

Похожие страницы ищи новой формулировкой по содержанию исходной статьи, с устранением дубликатов. `/findSimilar` помечен устаревшим в актуальной OpenAPI-схеме и не входит в основной набор. Для реальных связей цитирования используй источник, который возвращает эти связи; подключённый Firecrawl Research подходит для своей части индекса.

## Синтез и покрытие

Deep Search подходит для нескольких проверяемых элементов и узкой схемы; Agent — для многоступенчатого отбора и широких таблиц. В каждом результате сохраняй различие между найденными кандидатами и прошедшими проверку. Неполный список, пропуски, недоступный текст, `null` и остановка по бюджету явно отражаются в ответе.

Исторические версии подходят для сравнения страниц и повторяемой проверки. Они показывают сохранённую версию содержания, но поиск ранжируется текущими сигналами. Не заявляй, что это полное историческое состояние интернета.
