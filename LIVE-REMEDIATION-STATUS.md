# Состояние prepared-files-r6

UDR host 0.3.1 принимает готовые файлы через adopt_file с точными байтами и происхождением. Доставка по artifact_id требует отдельного точного разрешения и подавляет повтор подтверждённой отправки. 30 целевых проверок прошли, затем повторены из переносимого каталога; настоящая доставка и обратное чтение Telegram подтверждены. Установка поверх r5, повтор, отказ на неизвестной редакции и побайтовый откат проверены.

Исправления gateway-r5 и parser-r4 включены. Их прежние результаты сохранены как история, повторно за новые испытания не выдаются. Общие базы, ограничения и подписанные SDK не изменены. Новому владельцу требуется своя проверка.
