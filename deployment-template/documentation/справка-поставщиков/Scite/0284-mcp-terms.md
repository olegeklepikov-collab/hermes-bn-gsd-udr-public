## 2. Definitions

For the purposes of these Scite MCP Terms, the following terms have the meanings set forth below: 

**2.1 “MCP INTEGRATION”** means the technical implementation that allows scholarly content indexed within the Scite Platform to be accessed and retrieved through a Model Context Protocol connection in response to end-user prompts within supported LLM applications, and presented to such applications as contextual information in connection with user queries.

**2.2 “MODEL CONTEXT PROTOCOL”** or **“MCP”** means a standardized protocol that enables secure, controlled connections between LLM applications and external data sources, allowing contextual information to be provided to the model during user interactions without training the model on such data. 

**2.3 “TOOL USE”** means a single invocation of the Scite MCP Integration by an authorized end-user through a supported LLM application that triggers a retrieval of content from the Scite Platform. A Tool Use occurs each time the MCP Integration is called, regardless of the number of results returned in the response.

**2.3 “OUTPUT”** means any response, summary, analysis, translation, insight, or other content generated by a supported third-party LLM application in connection with use of the MCP Integration in response to Customer inputs and contextual information retrieved from the Scite Platform. For clarity, Outputs do not include Classifier Results or other content provided by Scite through the Scite Platform.
