# Hermes BN · GSD and UDR · текущий r2

Обезличенный комплект без пароля: очищенная от системных метаданных основа14октября clean-r2 и слойr2. Полезные файлы основы сохранены побайтово; старые входы, полномочия и личные состояния не наследуются.

**Обязательны оба архива из [recovery-set.json](recovery-set.json).** Слойr2 не применяется поверх прежнего слоя16октября. Точный состав подтверждается REMOTE-VERIFICATION.json после окончания публикации.

[Установка](deployment-template/CURRENT-SETUP.md), [восстановление](deployment-template/RECOVERY.md), [фактические проверки и ограничения](deployment-template/ACCEPTANCE.md), [версии](deployment-template/CURRENT-VERSIONS.json). Файловое дерево содержит обезличенные текущие источники; полные исполняемые среды находятся в материалах выпуска.

```sh
python3 restore.py --download --parts-dir ../hermes-parts --output-dir ../hermes-recovery
```

Нужен собственный доступGitHub CLI кэтому закрытому репозиторию. При наличии локальных частей флагdownload не нужен. Команда собирает и проверяет оба архива, не запускает службы. Полное содержимое и локальные инструкции можно перенести без авторизации во внешних исследовательских сервисах; модели и эмбеддинги новый владелец настраивает отдельно.

Подписанная параResearch/Foundation иGSD3.0.3 сохранены; собственные переходники отделены. Исторические сведения вbase/ не являются приёмкой другого владельца. Другая машина должна пройти свою проверку. Публикация новых файлов и удалённыеSHA подтверждаются отдельными квитанциями.

Заключительная сверка файлов и уточнение ранней статистики: [verification/2026-10-16/CURRENT-METADATA-NOTE.md](verification/2026-10-16/CURRENT-METADATA-NOTE.md).
