The Web of Science™ Researcher API provides REST-based programmatic access to WoS author records, with JSON output format and advanced search and filter capabilities.

Data available through this API includes information on documents, peer reviews, and basic metrics on people in the Web of Science. Claimed author records include personally curated information on a person’s publication and affiliation history. Unclaimed author records are algorithmically generated. Both claimed and unclaimed author records are identified by a unique ResearcherID.

### Who is the Researcher API for?

The Researcher API can be integrated into database systems and workflows to maintain high quality researcher metadata and metrics in your internal systems and research projects that need trusted data.

Some example use cases:

- Seed CRIS, FAR, or profiling systems with data, track and load basic metadata for new publications
- Discover researchers doing work in a given subject area and/or within an organization
- Compare basic metrics such as times cited, h-index, and document counts for researchers doing work in specific topic areas

### Subscription and access

Access to this API requires a paid license in addition to a Web of Science subscription. Don't hesitate to [get in touch with us](https://clarivate.com/academia-government/scientific-and-academic-research/research-discovery-and-referencing/web-of-science/web-of-science-apis-and-xml-data/) with any questions you may have.

This API uses an [API Key access](https://developer.clarivate.com/help/api-access#key_access). All APIs in our Developer Portal require registering an [application](https://developer.clarivate.com/help/application).
