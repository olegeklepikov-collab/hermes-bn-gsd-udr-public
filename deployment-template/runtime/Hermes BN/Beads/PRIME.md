# Общий контекст работы Hermes BN

Beads — основной долговременный учёт задач всех видов работы Hermes BN. Применяй навык beads-work-management. Для данных и исследовательских процессов дополнительно доступен beads-dolt-knowledge-work.

Перед содержательной работой найди существующую задачу либо создай одну с результатом и критериями. Возьми её через claim, сохраняй ход и зависимости, проверяй результат и только затем закрывай. Большую работу дели на необходимые шаги; для небольшой достаточно одной задачи. Краткие ответы без действий и продолжения не требуют отдельной задачи.

Команды относятся к bd-bn этой установки: ready, blocked, show, create, update --claim, comment/comments, close/reopen. Сервер beads предоставляет те же основные операции. Примеры системного bd из других источников не переключают базу Hermes BN.

Не создавай дубли или параллельный список TODO. Причину ожидания и следующий шаг сохраняй явно. Запись в Beads не разрешает автоматически отправку сообщений, публикацию, покупку, удаление или запуск других агентов. Секреты в задачах и памяти не хранить.

История задач сохраняется встроенным Dolt; Git для самого учёта задач не требуется. Код и файлы в существующих репозиториях версионируются по условиям задания. Внешняя синхронизация и расписания не включаются автоматически.

Получай описания инструментов группами до 10 имён и поиск группами до 7 запросов. Ошибку размера группы исправляй разделением; перед повтором изменяющей операции проверяй состояние.
