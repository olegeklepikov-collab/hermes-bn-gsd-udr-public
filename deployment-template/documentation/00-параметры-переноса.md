# Параметры целевой установки

Пакет предназначен для новой машины и допускает другого пользователя. Он содержит общую документацию и образцы, а не действующий профиль, библиотеку, подписку или авторизацию. Все идентификаторы и права определяются на целевой стороне.

## Обязательные значения

| Обозначение | Что выбрать заново | Тип |
|---|---|---|
| `${RUNTIME_ROOT}` | Каталог программ и независимых данных | Абсолютный путь целевой ОС |
| `${PROJECT_DIR}` | Рабочий проект | Путь |
| `${USER_HOME}` | Домашний каталог нового пользователя | Путь |
| `${STORAGE_ROOT}` | Выбранный диск/хранилище | Путь |
| `${MODEL_PROVIDER}`, `${MODEL_NAME}` | Поддерживаемые провайдер и модель | Строки |
| `${RESPONSE_LANGUAGE}`, `${TIMEZONE}` | Язык ответа и часовой пояс | Строки |
| `${PROVIDER_API_KEY}` / ключ конкретной службы | Собственный доступ пользователя | Секрет вне пакета |
| `${..._MCP_COMMAND}` | Установленная программа местного MCP | Исполняемый путь |
| `${CONTACT_EMAIL}` / `${EMAIL}` | Собственный технический контакт | Строка |
| `${BOT_USERNAME}`, `${TELEGRAM_ALLOWED_USER_IDS}` | Собственный бот и разрешённые пользователи | Строка/массив |
| `${DATABASE_USER}`, `${DATABASE_PASSWORD}` | Новые учётные данные SQL | Строка/секрет |
| `${DATABASE}`, `${WORKING_DATABASE}`, `${BRANCH}` | База и ветка нового проекта | Строки |
| `${WORKSPACE_ID}`, `${FOLDER_ID}`, `${PROJECT_ID}` | Объекты своего аккаунта/проекта | Идентификаторы |
| `${OBJECT_KEY}`, `${KEY}`, `${COLLECTION_KEY}` | Объекты своей библиотеки | Идентификаторы |
| `${FILE}`, `${PATH}`, `${LOCAL_FILE}`, `${OUTPUT_NAME}` | Собственные входы и выходы | Пути/имена |
| `${QUERY}`, `${QUESTION}`, `${TOPIC}` | Текущая исследовательская задача | Строки |
| `${EXPECTED_VERSION}`, `${ETAG}`, `${SOURCE_SHA256}` | Свежая версия/условие записи и сумма своего файла | Тип по схеме |
| `${PAGE}`, `${PAGES}`, `${RECORD_ID}`, `${RECORD_IDS}` | Страницы и записи своих входных данных | Число/массив по схеме |
| `${APPROVED_BUDGET}` | Явный предел разрешённого расхода | Число/структура по схеме |

Другие `${...}` образуются от имени параметра и имеют тот же смысл: значение задаёт получатель пакета. Для массивов/чисел заменяют **JSON-значение нужного типа**, а не просто текст внутри кавычек. Markdown сам не подставляет переменные. Поддержку окружения в конфигурации конкретной версии клиента проверяют отдельно.

## Разделение пользователей

Другому пользователю создаётся собственный профиль с собственными секретами и библиотеками. Данные прежнего аккаунта, токены, разрешения, боты, заявки в поддержку и доказательства доступа не входят в документацию. Перенос исследовательских данных — отдельная операция с выбором владельца/прав и формата.

Одно название проекта или программы не устанавливает принадлежность библиотеки. Перед записью проверяют фактический аккаунт, область, сервер/экземпляр и версию. Для Zotero идентификатор своего сервера получают заново. Для Dolt разрешённая база должна совпадать с механическим ограничением установленного переходника. Для Beads создаётся или явно выбирается своя база задач.
