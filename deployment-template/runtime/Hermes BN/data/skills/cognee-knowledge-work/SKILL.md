---

1. Используй инструменты сервера context. Описания запрашивай группами до 10 имён. knowledge_ingest принимает только одну разрешённую запись record_id или относительный path, явную область task/project/owner и request_id. Для больших материалов задавай offset/length; полного чтения по фрагменту не заявляй. Оригинал и SHA сохраняются до обработки; модельные шаги выполняют настоящие листовые агенты Hermes, без инструментов и рекурсии.
2. knowledge_query возвращает только адресный контекст (chunks/hybrid/graph/temporal/summaries), не окончательный ответ. source_quotes сверены с первичным текстом; graph context остаётся model_graph_unreviewed. При превышении размера читай context_ref через knowledge_manage(read_context), последовательно по offset.
3. Общий memory_recall(mode=hybrid) включает Cognee как дополнительный индекс. Не записывай результат поиска как независимое новое свидетельство. GSD проверяет выводы; UDR хранит оригиналы, договор работы и научное принятие.
4. knowledge_manage(enrich) строит сводки и возвращает фактические стадии. knowledge_manage(lesson,record_id,request_id,scope) обрабатывает явно сохранённое свидетельство. Типизированная запись trace поддерживает фактически выполненное действие; произвольную ошибку не выдумывай. Исходник и все части сохраняются, пределы SDK учитываются до записи. Отбор сохраняет исходные пороги уверенности и научный статус unreviewed. candidate_record_ids читай через memory_read; повторный request_id возвращает прежний результат. Отказы и превышения закрывают зависимый путь. no_accepted_lessons/skipped не означают созданный урок. Эти результаты — непроверенные производные, не новые правила исполнения.
5. knowledge_manage(read_source,doc_id) повторно читает сохранённый текст; forget удаляет только указанную производную, сохраняя первичный оригинал. Дочерние роли могут читать, но не строить, менять или обогащать.
6. Cognee имеет собственный конечный предел и общий ресурс родителя. При ошибке останови зависимую обработку, сохрани частичное состояние и причину. Отказ Cognee не означает отказ первичной памяти; не обходи обязательные контроллеры и не запускай второй управляющий цикл.
