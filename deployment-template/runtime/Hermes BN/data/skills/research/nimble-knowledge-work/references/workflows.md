# Процедуры исследования

| Сфера | Порядок | Проверяемые различия |
|---|---|---|
| Бизнес и рынок | Источники по разным направлениям → официальные документы и независимые сведения → research или dataset → проверка ключевых полей | Период, регион, валюта, определение рынка, планы и факты, связанные компании |
| Профиль компании | Готовый company-profile либо существующий профиль → исходные реестры и сайт → результат и trust → проверка значимых утверждений | Юридическое лицо, бренд, подразделения, дата числа сотрудников, оценки и отчётные цифры |
| Академические исследования | Термины и альтернативные объяснения → academic/lite и первичные издатели → чтение полного текста → академический research → таблица доказательств | Тип публикации, рецензирование, методы, выборка, ограничения, исправления и отзывы |
| Общие исследования | Вопрос, период и критерии → источники за и против → чтение → общий research → обоснованный синтез | Факт, заявление автора, интерпретация, неизвестное и противоречие |
| Документы и таблицы | General + content_type → проверка адресов → Extract/Media разрешённого документа → местный архив | Формат, полнота, версия, исходные единицы, ссылки на доказательства |
| Новости | News/lite + период → первичная публикация → Extract → текущая сводка | Дата события и дата публикации; недатированный источник не получает придуманную дату |
| Дополнение записей | Схема массива → input_data с известными полями → enrichment → проверка новых ячеек | pre_existing не проверено; пропуск NULL отличается от подтверждённого отсутствия |
| Исследовательская таблица | Критерии и предел строк → dataset_building с подготовленной схемой → результат → проверка источников, дублей и охвата | Число полученных строк не доказывает исчерпывающий охват |
| Корпус сайта | Map → выбранные адреса → Extract либо ограниченный Crawl → задачи и пакет → местные файлы | Карта адресов и прочитанные страницы; успех пакета и ошибки отдельных записей |
| Повторное чтение сайта | Каталог Templates → Get → входная/выходная схемы → запуск → сравнение с первичным содержанием | Шаблон опубликован и работает, а не только присутствует в каталоге |
| Повторный вопрос исследования | Сохранённые agent_id/run_id → статус/результат → при необходимости previous_interaction_id через API | Новое задание отличается от продолжения; прежние источники могут требовать обновления |

Для длительного задания сообщи фазу работы и верни идентификаторы; продолжай независимые действия между проверками. Не объявляй успех до готового результата. Уважай ограничения источников и доступ к данным; инструменты не разрешают действия за пределами запроса пользователя.
