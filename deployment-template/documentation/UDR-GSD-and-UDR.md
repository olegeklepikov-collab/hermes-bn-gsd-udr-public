# GSD and UDR для другого владельца

Полная программная поставка включает BN, GSD 3.0.3, действующий адаптер 0.2.13, Research 0.44.0b2, Foundation 0.14.0b1, весь каталог операций/навыков и нативные зависимости. Полные исходники и подписи пакетов сохранены. Личные ключи, авторизации, задачи, переписка, пользовательские данные и старые решения о принятии отсутствуют.

1. Проверьте MANIFEST и контрольные суммы до подготовки.
2. Выполните deployment/prepare.py с новым коротким каталогом R для BN и --init-local-databases. Будут созданы собственные ключи GSD и пустые базы.
3. Выполните deployment/prepare-udr.py --r-runtime НОВЫЙ_КОРОТКИЙ_КАТАЛОГ_R_UDR --timezone ВАША_ЗОНА. Указывайте собственную почту только при намерении передавать её API. Для теста на занятой машине задайте отдельный --host-bootstrap. Это не запускает службы и не переносит чужую приёмку.
4. Следуйте официальным source/docs/setup/README.md и трём документам спецификации/дорожной карты/передачи задания, затем ru/01–11. Сначала свои Neo4j, AgentMemory и SQL-права; Node/Python/Java и весь код входят в архив. Службы регистрируются только после проверки корней и свободных портов.
5. Выполните собственный OAuth-вход в ChatGPT либо выберите другого поставщика; отдельно введите ключ эмбеддингов защищённым местным способом. Все MCP и каналы остаются выключенными до проверки. Создайте своих ботов и укажите собственный ID владельца.
6. Настройте защищённый native-runtime.json через штатный configure_native_runtime.py подписанного Foundation. Выполните его миграции и provision_dolt_sql.py; создайте пустой Beads KWF. Старые root-map, пароли, статусы выпуска и approval-файлы не используются.
7. Включите runtime-policy и проверенные плагины UDR. Подключение BN настраивается через сохранённый native host adapter; нужны собственный source-manifest, транспортная привязка GSD, обязательные проверки и чистые независимые профили. Поставленные blueprint-профили не активируются до этого шага.
8. Проверьте CLI, обязательные отказы, реальную модель, роли и своё входящее сообщение/файл/разрешённую выдачу; создайте свою точку восстановления. Прежняя приёмка не является результатом новой установки.

Нативные двоичные файлы предназначены для macOS arm64. На другой ОС/архитектуре установите соответствующие версии по lock-файлам. Общие Homebrew-зависимости ожидают /opt/homebrew; не перезаписывайте чужие пакеты. Новая машина может потребовать системные инструменты и разрешения macOS. Результат не является образом ОС или копией SaaS-аккаунтов.
