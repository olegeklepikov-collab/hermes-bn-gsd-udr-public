# Hermes BN · GSD and UDR · полный выпуск r8

Самостоятельный выпуск 11 ноября 2026 года. Санитизированная поставка без пароля и прежних аккаунтов, данных и полномочий.

[Инспекция](INSPECTION.md) · [Установка macOS](INSTALL-macOS-Apple-Silicon.md) · [Текущий порядок](CURRENT-SETUP.md).

```sh
python3 restore.py --download --parts-dir ../hermes-parts --output-dir ../hermes-recovery
```

Один самостоятельный архив опубликован частями. Суммы и порядок задаёт recovery-set.json. Предыдущие основы/слои не требуются. Полный программный состав находится в архиве, исходники и шаблоны — в deployment-template/. Старые результаты приёмки не переносятся новому пользователю.
