# Деловые, научные и общие задачи

## Бизнес

Определи рынок, регион, период, единицу сравнения и одинаковые поля. Ищи официальный сайт, отчётность, первичную статистику и регулятора; затем добавляй независимые сведения. Topic finance подходит для финансовых источников, а general — для широкой деловой подборки. Country является приоритетом, а не доказательством географии.

Показатели сравнивай только с понятными единицами, валютами и периодами. Заявление организации обозначай как её заявление. Сохраняй свидетельство каждого поля, противоречия, отсутствующие значения и ограничения.

## Академические исследования

Сформулируй критерии включения, термины и период. Ищи несколькими разными направлениями, используй источники по дисциплине и первичные тексты. У Tavily нет отдельной гарантии полного дисциплинарного индекса. Для строгого корпуса применяй ограниченные домены; для широкого обзора не замыкай поиск на одном репозитории.

Проверяй DOI, версии, статус рецензирования, отзыв публикации и реальную дату. Отрывки и аннотация не равны полному тексту. Дата Tavily может означать обновление страницы; уточняй важную дату по источнику.

Сопоставляй дизайн, выборку, методы, эффект, неопределённость и ограничения. Research помогает синтезировать источники, но не подтверждает истинность автоматически. APA/MLA/Chicago требуют проверки самих библиографических данных.

## Корпус и извлечение

Map → выбор URL → Extract обычно даёт больше контроля, чем немедленный полный Crawl. Используй пути, домены, предел и запрет внешних переходов по заданному корпусу. Сохраняй полученные адреса, ошибки и неполноту. Целевые отрывки облегчают поиск конкретного значения, полное чтение нужно для структуры и контекста.

## Документы и Research

Исходные URL можно читать через Extract. Для файлов Research принимает только txt/md/json. Если нужен PDF/DOCX, сначала извлеки согласованный текст подходящим инструментом; передача этого текста Tavily требует разрешения на данный адресат. Не передавай весь рабочий каталог.

При загрузке созданного проверочного файла помечай сведения как пример. При частной таблице согласуй состав. Сохраняй различие между ссылкой на веб-страницу и ссылкой на файл как источник.

## Общие исследования

Используй advanced для узких проверяемых сведений и покрытия нескольких сторон вопроса; basic — для простого поиска. Новости проверяй по дате публикации и события. Изображения и их описания — отдельные возвращаемые сведения, их происхождение сохраняется; подпись модели сама по себе не подтверждает содержание изображения.
