# Полный программный доступ

Команда: `__HERMES_BN_ROOT__/bin/tavily-bn`.

Операции: search, extract, map, crawl, research-create, research-get, research-stream, usage, logs, batch-local. Ключ берётся из собственного профиля. Тело задаётся JSON-файлом через --input; ответ — через --output и сохраняется с правами 600. Заголовок с ключом не записывается в файл запроса.

```bash
'__HERMES_BN_ROOT__/bin/tavily-bn' search --input '/путь/к/запросу.json' --output '/путь/к/результату.json'
```

Для Research:
1. Создай задачу через research-create и сохрани request_id.
2. Запрашивай research-get --id [request_id]. Для расхода передай через --params файл {"include_usage":true}.
3. Продолжай пока pending/in_progress; completed или failed завершают ожидание. Сохрани content, sources, model и usage. После неопределённой сетевой ошибки продолжай известное задание, не создавай дубликат.

Research-stream принимает то же тело и требует --output. Команда сохраняет промежуточные события и конечный результат; stream_completed:true означает полученный done. Stream_id события не следует автоматически считать request_id задачи. При отсутствии ID и обрыве проверь журнал прежнего запроса, не перезапускай создание вслепую.

Batch-local принимает {"requests":[{"customId":"имя","operation":"search","body":{...}}]}. Поддерживает search/extract/map/crawl, два одновременных вызова и уникальные customId. Исследования создаются и отслеживаются отдельно. Ошибки отдельных элементов сохраняются и дают ненулевой код завершения.

Session_id можно передать через --session-id; автоматически создаётся непрямой UUID. Для нескольких этапов одной задачи используй один ID. Project_id через --project-id должен уже существовать в Tavily. Human_id и личные идентификаторы автоматически не передаются.

В Logs ставь filter_by_api_key:true и ограничивай период/число записей. Usage имеет лимит десять запросов за десять минут; не используй его как частый сигнал ожидания Research. Статус исследования проверяется отдельным запросом.

Официальный SDK 0.8.4 установлен в среде Hermes BN. TavilyClient и AsyncTavilyClient поддерживают все пять возможностей. Всегда явно передавай ключ собственного профиля и API URL. Не копируй дополнительные ключи моделей из примеров интеграций: модель Hermes уже настроена.

Официальный tvly CLI, локальный MCP и OAuth описаны как альтернативы. Стандартный CLI сохраняет ключ в ~/.tavily и может устанавливать навыки другим агентам. Для текущего независимого экземпляра выбрана команда собственного профиля на AgentRuntime2.

В действующем MCP доступны девять операций с полными схемами: Search, Extract, Map, Crawl, Research Create/Get/Stream, Usage и Logs. Локальный сервер передаёт запросы облачному Tavily и не открывает сетевой порт. Это позволяет использовать параметры, отсутствующие в официальном удалённом MCP.
