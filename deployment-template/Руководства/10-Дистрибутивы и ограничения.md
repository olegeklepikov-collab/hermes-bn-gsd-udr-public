# Проверка поставки

distribution содержит отдельные native каталоги трёх платформ, python-packages и индивидуальные requirements/environments, R-packages/R-environments, npm-packages и исходные lock-файлы, точные исходники/рецепты общей программной базы, контрольные манифесты. Несколько несовместимых Python-пакетов намеренно остаются в разных venv; нельзя объединять всё в одну среду.

Все скачанные файлы закреплены SHA-256; где издатель опубликовал digest/checksum/integrity, сумма сверена с ним. SHA-256, вычисленный только локально, не называется издательской подписью. Нативные установщики подписи проверяются средствами целевой ОС. Research/Foundation сохраняют свои проверенные исходные подписи; Apache POI сохраняет подпись/байты библиотеки.

Системные компиляторы/SDK и платформенные пакеты ОС относятся к выбранной редакции ОС. Они не скопированы из macOS как якобы Windows/Linux-среда. При отсутствии совместимого источника/дистрибутива либо необходимого контроля зависимый путь закрывается; сборка и реальное исполнение на целевой ОС записываются отдельно.

Установленное состояние на macOS содержит известные ограничения: нет гарантии смыслового чтения произвольного формата/внедрения; платные/закрытые площадки требуют своих прав; часть внешних API зависит от рассмотрения заявки/разрешения; отдельный выбор execute_code для арифметики был отклонён (hbn-6r3). Архив не объявляет эту ошибку исправленной и не подтверждает все удалённые подключения заново.

На Linux/Windows не выполнена аппаратная сквозная приёмка. Включение исполняемого файла и проход проверки хеша не являются его исполнением. Именно поэтому документы содержат отдельные критерии и предусмотренные закрытые отказы.
