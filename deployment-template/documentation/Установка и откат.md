# Установка, запуск, откат

Рабочий экземпляр обновлён из отдельного каталога staging. Предыдущие версии сохранены; исходные файлы конфигурации и изменённые файлы Hermes находятся в checkpoint. Миграции документарной памяти добавляют таблицы; существующие записи не удаляются.

## Управление

Собственный шлюз:

```sh
"__HERMES_BN_ROOT__/bin/hermes-bn-telegram" status
"__HERMES_BN_ROOT__/bin/hermes-bn-telegram" restart
```

Повторная публикация этой принятой локальной конфигурации — только при остановленном шлюзе и отсутствии действующих заданий:

```sh
"__HERMES_BN_ROOT__/hermes-agent/venv/bin/python" "__HERMES_BN_ROOT__/operator/remediation-20261013/publish.py"
```

Это команда данного экземпляра, а не переносимый установщик чужого аккаунта. Документарные инструменты подключены в основном и независимых профилях; навык — `document-corpus-completeness`.

## Проверки

Локальные дополнительные границы и документы:

```sh
"__HERMES_BN_ROOT__/hermes-agent/venv/bin/python" -m pytest "__HERMES_BN_ROOT__/operator/remediation-20261013/test_remediation.py" "__HERMES_BN_ROOT__/operator/remediation-20261013/test_documents.py" -q -p no:cacheprovider
```

Проверки Hermes запускать его штатным `scripts/run_tests.sh` из каталога исходников. Для GSD сначала импортировать стандартный operator, затем подключать каталог пакета: в поставке есть одноимённый каталог. Не задавать его как PYTHONPATH перед запуском Python. Реальные исследовательские проверки расходуют доступ к модели и создают явно обозначенные синтетические задачи; механические проверки этого не делают.

## Откат

1. Остановить свой шлюз и подтвердить прекращение действующих исполнителей. Сохранить новые после снимка материалы отдельно.
2. Распаковать полную зашифрованную копию в новый защищённый каталог. Проверить манифест до замены рабочего экземпляра.
3. Для точечного возврата к состоянию до ремедиации использовать checkpoint/core, checkpoint/udr, home-*/config.yaml и прежние версии Memory/GSD. Восстанавливать вместе код, политики, их контрольные суммы и все три профиля; смесь версий закрывает исполнение.
4. Для полного отката восстановить согласованные состояния SQLite, Dolt, Neo4j, документы, графы, индексы и настройки при остановленных писателях. Не запускать одновременно две копии одного бота или библиотеки.
5. На иной машине восстановить пути и нативные зависимости; R.framework устанавливается официальным подписанным пакетом, если его ещё нет. Не заменять чужие системные установки автоматически. Вход OAuth и разрешения macOS могут потребовать повторения.
6. После восстановления подтвердить обязательные контроллеры, чтение сохранённого источника, поиск индексов и один настоящий входящий запрос. Только затем возобновить работу.

Для другого пользователя применяется обезличенная поставка с пустыми состояниями и собственными ключами. Старые полномочия, подтверждения приёмки, Telegram ID и личные документы переносить нельзя.
