# Общая память Hermes BN — версия 1.0

Область: основной профиль BN, CLI, рабочий шлюз, отдельно GSD и UDR, настоящие дочерние агенты. Первичный журнал — отдельная SQLite BN; AgentMemory, Graphiti/Neo4j и Zvec — восстановимые производные. Нового управляющего цикла и Cognee нет: существующие компоненты покрывают задачу.

Области: владелец (общие сведения), проект (явно зарегистрированный рабочий каталог), текущая работа/сеанс. Дочерние роли наследуют область и только чтение. Сведения из памяти — данные с происхождением и версией; модельная запись не становится подтверждённым фактом или правилом исполнения.

Контекст: однократный адресный поиск перед ходом, компактное обязательное описание области и ограниченный набор целых записей. При большом результате — явные страницы и повторное чтение по ID, без обрезания самих записей. Обязательный контроль перед API проверяет доставку и область; отказ первичного журнала закрывает операции памяти. Отказ производного индекса отмечается и допускает чтение первичного журнала.

Serena — поиск символов и ссылок в разрешённом проекте; Mirage — чтение файлов в том же проекте. Переходники не допускают внешние пути, символические ссылки к секретам, запуск команд и запись файлов. Beads и Dolt сохраняют существующие назначения.

Этапы: 1) источники/интерфейсы и критерии; 2) код и отдельные испытания; 3) подключение всех профилей и допуск GSD; 4) реальные службы, CLI, GSD, UDR и шлюз; 5) отказы, восстановление и документы.

Приёмка: реальная запись и повторное чтение, совпадение версий/хешей, явные результаты каждого индекса, отсутствие доступа другой области, запрет записи дочерней ролью, доставка контекста в итоговые аргументы модели, сохранение работы независимых профилей и восстановление снимка. Наличие настроек само по себе не является успехом.
