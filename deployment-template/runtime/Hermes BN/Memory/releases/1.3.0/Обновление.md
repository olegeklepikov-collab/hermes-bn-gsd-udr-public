# Общая память 1.3.0

Единый безопасный разбор документов для обычного Hermes BN, UDR и GSD. Исполнитель bn-parser/1.0.0 и decoder_revision3 имеют собственные номера версий.

Разбор выполняется отдельным процессом с обязательной изоляцией ОС, без сети и ключей. Большие оригиналы обрабатываются адресными единицами с контрольными точками, без общего предела страниц или строк. Поддерживаются явные отказ, отмена, возобновление и квитанции происхождения. Извлечение не означает чтение моделью.

UDR поддерживает местный intake и продолжение сетевого fetch через parse. Сохраняются исходные контракты и подписанные SDK. Обычный read_file документа направляет в document_catalogue/extract/read/status; незащищённый запасной путь запрещён.

Совместимость с Cognee1.6.4 и прежними функциями общей памяти сохранена. Полный порядок — SAFE-DOCUMENT-PARSING.md и INSTALL-macOS-Apple-Silicon.md в корне поставки. Неподдержанные форматы, шифрование и неразобранные внедрения остаются явными пробелами.
