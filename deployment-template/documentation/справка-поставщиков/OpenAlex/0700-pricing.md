Pricing is simple and transparent: every account gets <strong>$1 of API usage per day for free</strong>, and if you need more than that, there are exactly two ways to get it — <strong>pay as you go</strong>, or an <strong>annual plan</strong>. <h2 id="free-1-per-day">Free: $1 per day</h2>
<p>Create a free OpenAlex account and you get an API key with <strong>$1 of usage per day</strong> — no payment method required. That’s enough for most research and personal projects. The budget resets every midnight UTC; how usage maps to API calls is covered in <a href="/access/example-costs/">Example costs</a>.</p>
<h2 id="pay-as-you-go-prepaid-usage">Pay as you go: prepaid usage</h2>
<p>If you need more than $1 on a given day, add <strong>prepaid usage</strong> in $1 increments, self-serve, on the <a href="https://openalex.org/pricing">pricing page</a>. Prepaid usage is only drawn down after your free daily budget runs out, and it expires 3 months after your most recent purchase. See <a href="/access/buying-and-renewing/">Buying &#x26; renewing</a> for the mechanics (including VAT invoices).</p>
<h2 id="annual-plans">Annual plans</h2>
<p>For organizations and heavy users, three annual plans bundle a much larger daily API budget with priority support and other benefits — while directly supporting OpenAlex as open infrastructure. Each plan includes everything in the one before it. Full benefit details and activation instructions live on each plan’s page.</p>
<h3 id="member--5000year">Member — $5,000/year</h3>
<p>The entry plan for organizations that rely on OpenAlex. You get a <strong>$20/day API budget</strong> ($7,300/year of usage — a 32% saving over pay-as-you-go), the <strong>admin dashboard</strong> for managing your organization’s users and billing, and <strong>community representation</strong>: advisory-board nominations and a seat at our quarterly supporter meetings. Academic and government institutions also get the <strong>affiliation editor</strong> and free <strong>Unsub</strong> access. <a href="/access/member/">Full details →</a></p>
<h3 id="member--10000year">Member+ — $10,000/year</h3>
<p>Everything in Member, plus a <strong>$100/day API budget</strong> ($36,500/year of usage — a 73% saving), <strong>basic support</strong> (help with critical API bugs), and <strong>daily sync</strong>: a complete daily snapshot of the database plus API filters that return everything new or changed since any date. <a href="/access/member-plus/">Full details →</a></p>
<h3 id="partner--from-20000year">Partner — from $20,000/year</h3>
<p>Everything in Member+, plus a <strong>$200+/day API budget</strong> sized to your needs, <strong>full ticket-based support</strong> for all issues, and — for academic and government institutions — <strong>3 power-user accounts</strong> with extra-high API limits and <strong>5 hours of consulting</strong> per year. Partner pricing starts at $20,000 and scales with your use case. <a href="/access/partner/">Full details →</a></p>

<h2 id="the-pdf-sync-add-on">The PDF sync add-on</h2>
<p>OpenAlex caches more than <strong>50 million open-access full-text PDFs</strong> (plus machine-readable TEI XML). Any annual plan can add the <strong>PDF sync service</strong>: persistent read access to the content archive’s S3-compatible bucket, so you can sync the complete archive to your own storage — and keep receiving new PDFs as they arrive, continuously.</p>
<p>Note what’s for sale here: <strong>sync, not PDFs</strong>. In keeping with our <a href="#free-data-paid-services">free data, paid services</a> model, we don’t sell the documents — we sell the service of delivering the living, continuously-updated archive to your infrastructure. The add-on requires an active annual plan (any tier) and is priced separately; <a href="/cdn-cgi/l/email-protection#4231232e2731022d32272c232e273a6c2d3025">contact sales</a> for a quote. For the technical side — bucket layout, manifests, and smaller-scale download options — see <a href="/access/fulltext/">Fulltext</a>.</p>
<h2 id="free-data-paid-services">Free data, paid services</h2>
<p>Scholarly metadata is treated in most markets as “the new oil” — value is captured by <em>limiting</em> access. OpenAlex takes the opposite position: the data is a public good, released under a <a href="https://creativecommons.org/public-domain/cc0/">CC0</a> public-domain license with no “personal use only” carve-out and no permission to ask. Revenue comes from time and services layered on top — serving, freshness, support — rather than from the data itself, mirroring the <a href="https://openscholarlyinfrastructure.org/">POSI</a> principle of revenue based on services, not data.</p>
<p>This is also structural insurance: OpenAlex is a US 501(c)(3) nonprofit, all code is open source, and the full dataset is openly downloadable — so if we ever lost our way, anyone could take the data and code and continue the mission.
