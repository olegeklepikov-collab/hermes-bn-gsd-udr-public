# Средства восстановления для macOS arm64

Включены age 1.3.2, zstd 1.5.7 и необходимые местные библиотеки zstd. Они используют системные библиотеки macOS; установки Homebrew для распаковки не требуется. Лицензии находятся в licenses. Ключей и учётных записей в этом каталоге нет.

Сначала проверьте SHA256SUMS, полученный вместе с архивом, затем используйте новый, ещё не существующий каталог назначения.

Обезличенный комплект:

```bash
bash '<КАТАЛОГ_СРЕДСТВ>/restore.sh' '<АРХИВ.tar.zst>' '<НОВЫЙ_КАТАЛОГ>'
```

Закрытая полная копия:

```bash
bash '<КАТАЛОГ_СРЕДСТВ>/restore.sh' '<АРХИВ.tar.zst.age>' '<НОВЫЙ_КАТАЛОГ>' '<ОТДЕЛЬНЫЙ_ФАЙЛ_КЛЮЧА.agekey>'
```

Сценарий только распаковывает. Он не запускает службы и не восстанавливает облачную синхронизацию. После распаковки прочитайте README.md и выполните verify.py до первого запуска.

Для verify.py подходит Python 3. Если его нет в системе, можно использовать включённый самостоятельный Python: `runtime/Hermes BN/runtime/python/cpython-3.13.14-macos-aarch64-none/bin/python3.13` в обезличенном комплекте либо `Hermes BN/runtime/python/cpython-3.13.14-macos-aarch64-none/bin/python3.13` в полной копии. Укажите полный путь к нему, к verify.py и к каталогу распаковки.

На другой ОС или архитектуре установите подходящие для неё age, zstd и libarchive. Включённые двоичные программы macOS на ней не выполняются; исходники и зафиксированные зависимости исследовательской среды находятся внутри комплектов.
