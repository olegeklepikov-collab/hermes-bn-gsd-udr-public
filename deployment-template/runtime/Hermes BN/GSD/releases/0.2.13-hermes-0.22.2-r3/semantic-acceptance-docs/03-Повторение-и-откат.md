# Повторение, установка и откат

Основной экземпляр использует неизменённое ядро Hermes f97608f178d1ffeca59860195ab7da295f7c8e5f с ранее испытанными обязательными контролями. Изменения 0.2.3 находятся в адаптере ролей. Канонические источники GSD не изменены.

## Повторение

1. Используйте отдельные каталоги профиля, состояния, ключей и рабочей области. Существующие задания кампании не запускайте повторно с тем же request_id.
2. Настройте отдельный вход в модель; пароль, ключи и действующие базы в пакет не входят.
3. `harness/setup.py` и `harness/prepare.py` воспроизводят изолированный профиль и критерии; параметры путей следует изменить под новую машину. Материал `materials` и последовательность редакций сохранены.
4. Запуск конкретных групп: `python harness/run_campaign.py НАЧАЛО КОНЕЦ`. Конец исключён. Не включайте группы, предназначенные только для проверки сохранённых результатов. Порядок — `plan/groups.json`.
5. Проверка сохранённых результатов: `python harness/review_campaign.py`; итоговая проверка полноты и доставок: `python harness/report.py`.
6. Проверки кода запускайте через `hermes-agent/scripts/run_tests.sh /путь/к/пакету/tests -- --gsd-settings /путь/к/операторским/settings.json`.

Продукты модели имеют статус unreviewed. Матрица удостоверяет испытание в указанной области, а не даёт модели права повысить статус или принять чужое разрешение. Перед новым воспроизведением задайте отдельную кампанию и бюджет; перенос ключей/учётных данных другого пользователя не требуется.

## Установка и откат адаптера

Для нового независимого профиля: `python configure_profile.py --home ... --core ... --bundle ... --operator ... --state ... --workspace ...` сначала без `--apply`. В существующем профиле сохраняются старые лимиты, состояния и ключи; недопустим скрытый сброс учёта.

Для отката остановите процессы данного профиля и восстановите снимок конфигурации, созданный перед переключением, командой `python rollback_profile.py --home ... --snapshot ... --apply`. Проверка отпечатков защищает более поздние пользовательские изменения. Состояние, затраченный бюджет и неизвестные исходы не откатываются. Прежний выпуск 0.2.2 и его архив сохраняются.
