# Расширенные параметры и программные операции

Основной путь — MCP. В текущей схеме Firecrawl некоторые свободные объекты (`schema`, `body`) объявлены закрытыми без свойств, а `formats` разрешает только строки. Это ограничивает описание сложной схемы JSON, сравнение определённых полей и тела Monitor в модели. Для таких запросов используй прямой API через подготовленную команду `firecrawl-bn`; ключ берётся из того же профиля, не передаётся в командной строке.

Команда: `__HERMES_BN_ROOT__/bin/firecrawl-bn`.

Сначала сохрани тело запроса в JSON-файл задачи. Пример точной схемы извлечения: `__HERMES_BN_ROOT__/Firecrawl/schema-request.json`.

```bash
'__HERMES_BN_ROOT__/bin/firecrawl-bn' scrape --input '/путь/к/запросу.json' --output '/путь/к/результату.json'
```

Доступны `scrape`, `batch-scrape`, `batch-status`, `browser-create`, `browser-execute`, `browser-stop`, `monitor-create`, `monitor-update`, `monitor-get`. Состав параметров бери из действующей официальной документации, а не из имени команды. Для операций с заданием укажи `--id`. Команда пишет файл ответа с правами 600; ключ не сохраняется в результате. При ошибке она возвращает ненулевой код. Не повторяй автоматически создание задания после неопределённого исхода.

Пакет Scrape используй для известного списка URL; сохраняй ID и забирай результат через `batch-status`, проверяя ошибки и пагинацию. Для массива неизвестных страниц используй ограниченный Crawl или Agent.

Самостоятельный браузер: создать с короткими `ttl`/`activityTtl`, выполнить конкретное чтение публичной страницы, закрыть в любом исходе через `browser-stop`. Текущий API использует пути `/v2/interact`, `/v2/interact/{id}/execute` и `DELETE /v2/interact/{id}`; слово Browser сохраняется в названиях SDK. Не выводи адреса подключения и живого просмотра в публичный отчёт. Не используй вход на сайты или сохранённые профили без отдельного разрешения.

Monitor: создание не принимает поле `status`. Чтобы подготовить пример, создай его без получателей с отложенным расписанием, немедленно выполни `monitor-update` с `{"status":"paused"}` и проверь `monitor-get`. Рабочую частоту задаёт пользователь. Paused нельзя запустить через Run; для однократного теста последовательно возобнови, запусти и снова поставь на паузу, затем забери конечную проверку.

Расширенные форматы Scrape, включая JSON Schema и `changeTracking` с `modes:["json"]`, передаются объектами в `formats`. Научные номера страниц и границы обработки проверяй в ответе. Самостоятельное принятие условий и отправка сообщений не являются операциями этой команды.

Документы: https://docs.firecrawl.dev/features/scrape , https://docs.firecrawl.dev/features/browser , https://docs.firecrawl.dev/features/monitoring .
