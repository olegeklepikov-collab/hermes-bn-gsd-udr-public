# Проверка комплекта r8

Дата: 11 ноября 2026 года. Документы обновлены по фактическому коду r8. Новая установка и ремонт существующего экземпляра разделены. Команды подготовки проверяются на отдельной копии macOS arm64; настоящие модельные и Foundation-испытания описаны в «06 — Что проверено в r8.md».

Порядок: сначала получить текущий recovery-set и проверить архив, затем подготовить отдельную установку, настроить собственные службы и доступы, выполнить полный цикл и пробное восстановление. Чужие квитанции не заменяют приёмку нового владельца.

Для установленного экземпляра применяется «05 — Исправление установленной копии.md». Не повторяйте создание пустых баз поверх данных. При неизвестном местном OCR автоматическая замена запрещена, предусмотрен profiles-only.

Windows и Unix имеют инструкции нативного переноса компонентов. Полная эквивалентность этой macOS-сборке на них не подтверждена. Изолированный процесс OCR требует адаптации к ОС, проверки не удаляются.

Средства загрузки, точные размеры, SHA и ссылки согласуются с выпуском при публикации. Старые контрольные суммы и частичные слои к r8 не применяются. Прямое испытание удобства установки новым пользователем не проводилось.
